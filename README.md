# TapScene 点演

[业务功能](#业务模块) · [页面安排](#页面与流转) · [数据表](docs/architecture.md#数据层) · [API/SDK](docs/architecture.md#应用接口层) · [当前任务](docs/tasks.md)

把手机录屏整理成可点击、可分支的演示，用于成果展示、方案评审和短流程教学。
创作者在 Android 手机上制作，观看者按提示体验已有素材支持的有限流程，无需原 App 账号。

当前只有产品与开发说明、文档 CI，尚无产品实现。下面是首版目标，不代表功能或性能已经验收。
日常只维护三份文档：本页讲业务和逐页设计，[架构与开发约定](docs/architecture.md)讲怎么做，[当前任务](docs/tasks.md)讲接下来做什么。

## 一次完整使用

导入录屏 → 整理步骤 → 编辑热点和分支 → 遮挡隐私 → 检查实际输出 → 预览各路径 → 交付。
全部创作操作在手机完成；动画渲染使用电脑或作者明确选择的云环境。

## 业务模块

| 模块 | 输入 → 用户动作 → 产出 | 关键规则 |
|---|---|---|
| 项目与素材 | 名称、演示目标、明确选择的录屏/截图 → 新建、裁剪、追加、替换 → 本地项目、活动草稿、私有素材副本 | 不登录也能制作；取消文件选择不留下空项目。截图是作者编排，裁剪不改源文件。 |
| 本地候选整理 | 素材范围 → 本地分段、OCR、热点建议 → 待确认状态、动作、说明和重复状态建议 | 不上传原片；人工确认后才进正式图。分析失败可手工取帧，不能覆盖已编辑内容。 |
| 步骤与状态 | 候选或手动取帧 → 调代表帧、标题、说明、排序、拆分/合并 → 有稳定 ID 和来源的状态 | 同标题不代表同状态；表单、弹窗、键盘、滚动位置不同不能自动合并。排序不改边。 |
| 动作与分支 | 状态画面、矩形、已有目标 → 画热点、选目标、写选择标签、接录制过渡 → 有限图 | 只允许枚举动作；不执行原 App、不采集真实输入。作者跳转须确认；缺录结果留草稿，不能交付。 |
| 隐私处理 | 画面、过渡、疑似敏感线索 → 加不透明遮挡、改文案 → 遮挡配置及需重新生成的输出 | 视频仅固定多块遮挡，覆盖完整运动范围；不跟踪、不补背景；原音轨全部移除。 |
| 动画区域 | 最终脱敏画面 → 框选、命名、分组、设叠放次序与锚点 → 可见区域裁片与坐标 | 区域是截图裁片；不恢复控件、React 代码或隐藏背景。改底图/遮挡后裁片及复核失效。 |
| 试走与检查 | 当前草稿 → 从起点/当前步预览、逐边走通、检查关键路径 → 可定位问题与覆盖记录 | 播放器上一步按实际历史；允许显式回访，不允许自动循环。图变更使相关覆盖失效。 |
| 安全成品与复核 | 固定草稿修订 → 生成脱敏文件、重解码、审阅实际像素/文字/整段视频 → 封存的不可变版本 | 自动检查只找线索；作者复核绑定输出摘要。失效复核、未确认候选、断边、缺媒体均阻断交付。 |
| 离线交付 | 已封存版本 → 导出纯数据观看包、系统保存/分享 → Android 播放器可导入的离线演示 | 接收者先安装播放器；不是可双击运行的 HTML/ZIP，也不是原工程备份；发出的包不能远程收回。 |
| 托管与版本 | 已封存版本、邮箱账号、有效期 → 上传、完成发布、复制链接、逐版撤销 → 固定版本 HTTPS 链接 | 只上传复核后的安全资产；旧链接不随编辑改变。上传失败不公开半成品，撤销以服务端确认成功为准。 |
| AI 交付与回流 | 已封存图、有限访问路径、区域、画布 → 导出 AI 包；选择外部兼容包并核对差异 → AI 数据包或独立新草稿 | 选路径不自动丢掉其他已纳入分支；包不含执行代码。回流重新验证、清空外部复核结论，不覆盖、不自动发布。 |
| 恢复与维护 | 已保存草稿、任务检查点、本人安全包 → 恢复任务、局部替换、复制新草稿、清理 → 保留原项目与旧交付的独立结果 | 源片丢失不能靠账号恢复；删除项目、撤销链接、删缓存是三个动作，各自说明影响。 |

## 页面与流转

主流程：项目首页 → 导入与裁剪 → 候选确认 → 步骤卡编辑 → 单步画面编辑 → 预览 → 检查与成品复核 → 离线包 / 托管链接 / AI 工程包。

底层状态由用例返回，UI 不自行宣布“已保存、已复核、已发布”。容量政策共用一份配置；各入口在相关操作前显示当前用量和超限原因，不用首页统计卡代替工作内容。

| 操作阶段 | 页面 |
| --- | --- |
| 创作 | 01 项目首页、02 导入裁剪、03 候选确认、04 步骤卡、05 单步编辑、06 过渡编辑 |
| 检查与交付 | 07 预览、08 检查清单、09 成品复核、10 交付、11 AI 配置、12 任务详情 |
| 管理与导入 | 13 账号、14 托管版本、15 外部包导入、16 演示库、18 设置 |
| 观看 | 17 正式播放器，含开场、分支选择、过渡、完成与错误页 |

<details>
<summary>01 项目首页</summary>

- 顶部：TapScene 标题、设置；列表内可搜索项目。底部仅“项目 / 演示库”切换和醒目的“新建项目”。
- 主体：最近修改的真实项目行，显示名称、最近修改时间、步骤数、待处理问题和任务状态；未复核画面用中性封面，安全封面只能来自已复核产物。
- 点项目进入 04；点该行任务进入 12。更多菜单为“重命名、复制、管理发布、删除”，避免每行堆按钮。
- 新建弹层只填名称、演示目标，随后进入 02；文件未确认导入前不登记空项目。复制立即产生独立项目和草稿。
- 空态写“还没有项目”，给“选择录屏”和“导入自己的演示包”两个真实入口；示例若提供，清楚标为样例，不混充用户项目。
- 删除确认写清本机素材/草稿将丢失，以及托管链接仍存在；有发布时可先跳 14 管理，不能把删除项目当撤销。启动发现中断任务时，项目行显示“继续处理 / 查看原因”。
- 调用：`ListProjects / CreateProject / CopyProject / DeleteProject / ObserveJob`；不调用发布或登录 API。

</details>

<details>
<summary>02 导入与裁剪</summary>

- 顶部：返回、项目名或“新建项目”；主体为素材预览、片段列表、当前片段起止时间轴和时长/空间提示；底部主按钮“导入并整理”，次操作“再选素材”。
- 文件通过系统选择器、相册指定项或分享入口进入。录制提示只讲“用示例数据、关闭通知、关键画面稍停”，不申请无障碍或接管其他 App。
- 拖动起止点只改变引用区间；“取当前帧”可创建静态步骤；追加素材先独立整理，完成后让用户指定接到哪里，不自动覆盖同名页面。
- 检查格式、方向、可解码性、限额和临时空间后才启用主按钮。黑屏/保护画面、未知格式或空间不足给具体文件和处理建议，允许替换、裁短或取消。
- 正在复制显示真实已完成字节；进入分析后转 12，再回 03。取消不保留半份素材，不影响原项目；已经完整导入的素材可保留用于手工整理。
- 返回若有未确认裁剪，弹层给“继续编辑 / 放弃本次选择”；原有源文件和步骤不变。来源失效时可重新选择原文件，不能偷偷换成近似素材。
- 调用：`InspectSource / ImportSource / TrimSource / AnalyzeSources`；全部本机，无网络 API。

</details>

<details>
<summary>03 候选确认</summary>

- 顶部：“整理结果”、来源片段入口；主体为纵向候选步骤，卡片含代表帧、时码、建议标题、热点数和待确认标记；底部“将已确认项加入项目”。
- 点卡片打开确认面板：调代表帧/前后分界、改标题、回看原片、保留或舍弃；动作候选逐条显示“从哪里到哪里”，不会随勾选画面自动获准。
- 疑似重复状态用对比弹层并列两张画面、文字差异、进入/离开动作；默认保留两者，明确确认才合并，可撤销。
- 热点候选可逐项调整或留待 05 处理。相邻录制帧不自动证明点击因果；作者指定的新跳转明确标为“作者编排”。
- 无候选时给“手动取帧”；分析局部失败显示该片段原因和重试入口，已确认内容仍保留。暂不确认可存为建议，但不能混进可交付图。
- 返回保存已确认进度；重新分析只添加建议，不覆盖人工标题、热点或既有状态。完成进入 04，并标明仍待处理的建议。
- 调用：`ConfirmCandidates / UpdateState / CompareStates / MergeStates / UndoEdit`；读本机 `Source`，不向播放器公开来源路径。

</details>

<details>
<summary>04 步骤卡编辑</summary>

- 顶部：项目名、准确的保存状态、撤销及更多；主体：纵向步骤卡；底部固定“加步骤 / 预览 / 检查与交付”。不把完整关系图缩成手机大画布。
- 卡片显示画面、标题、起点/终点、出口标签及待处理问题；点画面进 05，点出口展开当前步和相邻目标的局部分支，点说明就近修改标题/讲解。
- 拖动只整理列表顺序；“设为起点、设为终点、插入这条路径、复制步骤、删除”在当前卡更多菜单。只有“插入这条路径”才让用户选定并重连一条边。
- “加步骤”弹层为“从现有素材取帧 / 追加录屏或截图 / 建待补录位置”。待补录卡显示占位说明，不能冒充已录结果；补素材后再确认连接。
- 项目更多菜单放“素材、版本、项目设置”。素材面板列来源和引用步骤；替换/删除前列受影响状态、热点、边、区域及复核，确认后回到定位问题列表。
- 空项目给添加素材入口；保存失败保留屏幕中的编辑并显示“重试保存”，不能显示已保存；恢复应用时回到最近已保存位置。删除与合并有撤销，退出编辑层不丢已确认编辑。
- 调用：`UpdateState / UpdateEdge / ReplaceSource / UndoEdit / ValidateDraft`；导航至 `PreviewDraft` 或检查页，不直接读写 DAO。

</details>

<details>
<summary>05 单步画面编辑</summary>

- 顶部：返回、步骤名、撤销、更多；点名称打开标题/说明表单。主体始终以当前画面为中心，底部一条“画面 / 热点 / 分支 / 遮挡 / 区域”模式栏，同一时刻只显示该模式的上下文控件。
- 画面模式：选择代表帧、裁剪区间、来源回看；来源和原片只能在标明“本机原素材”的私有视图查看。未生成安全文件时显示“编辑预览”，不能把遮挡覆盖层标成已脱敏输出。
- 热点模式：点画面新建矩形、拖动/缩放；选中后弹出标签和“选择动作”面板。目标选择器显示状态名、缩略图、来源类别，支持进入已有状态或明确结束；多结果展开带标签的选择项，不猜真实条件。
- 分支模式：主体下方只列当前步出口；“添加选择”填写标签并选目标/过渡；“作者编排”需确认。录制过渡点入 06。删除目标或改连线后立即定位失效引用，不把孤边藏起来。
- 遮挡模式：仅“不透明遮挡、移动/改尺寸、删除”三个上下文动作；疑似敏感文字作为待检查提示，可手动补块。遮挡改动提示相关输出/封面/区域要重做，视频遮挡在 06 调整。
- 区域模式：在匹配当前修订的安全派生图上框选；面板填写名称、组、叠放次序、裁片内锚点，预览标明“截图裁片”。没有安全底图时先“生成安全预览”；越界拒绝，底图变化后旧裁片显示待重生，绝不从原图补隐藏像素。
- 画布缩放与选区拖动分开手势/手柄；触摸入口按至少 48 dp，扩大命中范围但不改语义矩形；拥挤时用“对象列表”选热点/遮挡/区域，播放也提供文字动作。关闭面板只撤销未确认面板值，返回先退模式，再回 04。
- 调用：`UpdateState / UpdateHotspot / UpdateEdge / UpdateRedaction / UpdateRegion / UndoEdit`；热点用状态归一化坐标，区域用安全图像素，UI 经坐标适配器换算。

</details>

<details>
<summary>06 录制过渡编辑</summary>

- 顶部显示“起始步骤 → 目标步骤”；主体为预览、裁剪时间轴和固定遮挡；底部“保存过渡”，旁边“改为静态切换”。
- “选择片段”仅选择已导入来源和时码；显示单段与全项目累计时长。首版单段不超过 10 秒、累计不超过 60 秒，超出不能保存为可交付过渡。
- 本地原片回看与实际输出预览明确分开；固定遮挡覆盖整段，移动信息要覆盖完整运动范围，遮住了关键动作时建议静态前后状态。
- 提供播放、暂停、逐帧定位和重放；原音轨输出统一移除，没有“保留原音”开关。保存配置后显示“待生成/待整段复核”，不等于已审阅输出。
- 取消返回 05 并保留原绑定；坏帧、解码失败可重选片段或改静态，不能取首尾帧冒充视频已检查。
- 调用：`UpdateEdge / UpdateRedaction / InspectSource`；实际输出生成与逐段复核复用 09/12。

</details>

<details>
<summary>07 创作预览</summary>

- 顶部：“草稿预览”、修订号、退出到编辑；主体与成品使用同一安全媒体播放组件，额外显示当前状态和边覆盖调试层；底部为文字动作、上一步、重新开始。
- 进入弹层选“从起点 / 从当前步骤”。安全预览缺失或已过期时先生成，失败回 12；不能拿原片充当成品预览。此时可播放尚未最终复核的安全候选并标“未复核”，不要求先满足交付覆盖门槛；局部预览遇缺失目标明确阻断该动作。
- 点击只沿当前边走，过渡播放期间锁定重复点击；过渡有暂停、跳过到该边已选目标。上一步按访问历史，画面内返回热点仍按作者设定的边运行。
- “回到编辑此步”进入 05；“尚未试走的动作”打开局部列表，点某项定位出发状态。覆盖记录绑定图摘要，不能因打开页面就算试走。
- 到终点显示结果与“返回分支 / 从头再看 / 回编辑”；关键路径和未覆盖边回 08 统一检查，不声称无限回访路径已穷举。
- 媒体失败给重试或跳过当前过渡到既定结果，不跳猜测状态；关闭、重来或切步骤会取消旧媒体回调，不能随后被旧回调带走。
- 调用：`PreviewDraft / PlayRelease / ValidateDraft`；预览和正式播放复用纯状态机，预览快照不登记为已封存版本。本地记录图对应的 `edge` 覆盖，不调用托管接口。

</details>

<details>
<summary>08 检查清单</summary>

- 顶部：“交付检查”、本次草稿修订；主体按“结构与路径 / 隐私及文字 / 媒体与体积”分组，阻断项在前；底部主按钮“生成待复核成品”。
- 每条问题含人能读懂的原因和“去修正”，直接定位步骤、热点、边、文案或片段；提醒与必须解决项用文字区分，不仅靠颜色。
- 结构检查包含起点/终点、断边、缺录目标、未确认候选、热点冲突、非法循环、全部边试走和指定关键路径。草稿中不纳入交付的孤立内容须明确列出、由作者排除，不能悄悄丢弃。
- 隐私部分列待处理提示、失效原因和待复核对象；“未检出线索”不等于通过。缩略图、封面、说明、选择项、文件名/元数据都属于成品检查范围。
- 初次进入尚无成品时，先解决可编译结构问题再生成；生成后进入 09。原图上的复核不能替代实际输出复核，不用一个“全部安全”总勾选绕过对象。
- 修正后重算相关问题和覆盖；生成任务固定修订，后续编辑会显示“草稿已有新改动”，旧结果不能标成当前草稿已通过。取消生成回清单，已有保存内容不受影响。
- 调用：`ValidateDraft / BuildCandidate`；读 `Issue.subjectId` 和复核失效结果定位，任务详情进 12。

</details>

<details>
<summary>09 成品逐项复核</summary>

- 顶部：“复核实际输出”、待复核数量和候选版本；主体显示真正重编码后的图片/视频与文字，底部“发现问题 / 确认本项并继续”。
- 图片可缩放；视频提供完整播放、暂停、逐帧和重放，记录完整审阅进度，不能只看首尾就完成。检查音轨移除结果及解码异常；播放一遍本身不自动代替人的确认。

## 少量硬边界

- 只模拟已录制或作者明确补充的内容，不调用原 App，不真实登录、下单、支付、发消息或提交表单。
- 缺失页面和业务结果不能凭空补成“已验证”；缺素材可留在草稿，不能进入交付路径。
- 原录屏、原 OCR、未脱敏像素、源路径和编辑历史留在本机私有域，不进入交付包、日志或未授权网络。
- 敏感草稿和缓存排除系统云备份；设备迁移排除需实测。自动保存不防卸载或丢机，删除项目不自动撤销链接。
- 首版不提供云 AI，不允许本地分析 SDK 的非必要指标外传；手工兜底不能替代最终要完成的本地 OCR。
- 外部包、JSON 和文字都视为不可信数据：不执行脚本/表达式，不从包内 URL 下载媒体；坏包隔离，不破坏已有项目。
- 只请求用户所选文件所需权限，不申请通讯录、全盘照片或无障碍控制权限，不绕过受保护录屏。

首版不做任意 App 克隆、复杂手势、考试打分、团队实时协作、企业权限、观看统计或通用视频剪辑。
iOS 原生创作、云 AI、自动遮挡跟踪、配音、更多编码、工程云备份和高级分层留待后续明确需求。

## 首版设计限额

以下是待实测的设计上限，不是已证明的容量或性能；不支持或超限时说明原因，不静默截断。

- 状态推荐 5–20 个，上限 40 个；最多 80 条边，每状态最多 6 个热点。
- 每项目最多 3 段录屏，总时长 ≤5 分钟，单段 ≤3 分钟、≤200 MiB；全部原素材 ≤500 MiB。
- 录屏为 MP4/H.264/SDR、固定竖屏，最高 1080×2400、≤60 fps；混合方向、HDR 和未知编码先拦截。
- 补充截图为 PNG/JPEG，最多 20 张，单图 ≤12 MP 且 ≤10 MiB。
- 视频过渡单段 ≤10 秒，合计 ≤60 秒，统一无原音轨。
- 每个交付包及解压后资产总量均 ≤50 MiB。
- 同项目最多 5 个有效托管版本；有效期可选 1/7/30 天，默认 7 天。

最低 Android、目标机型、浏览器兼容和性能阈值在实现前用小样确定；尚未进行真机和性能验证。

## 怎么算可用

用无真实个人信息的样例，手机上完成主路径和两个分支、脱敏复核、导出、离线及网页观看。
预览覆盖全部边和关键路径；实际检查错误合并、短暂敏感帧、访问历史、坏包、中断恢复、发布隔离和到期撤销，再验证两种画布渲染及 JSON 回流。
界面只展示真实数据、进度和可用操作；保留有用引导、空态和错误恢复，不放营销词、假按钮或假成功。
可以分小步交付可独立使用的功能，但上面的核心能力都完成并通过相应检查后，才称为完整首版。
