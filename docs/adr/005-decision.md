# ADR 005 不可变发布与逐请求撤销

状态：Proposed。日期：2026-10-09。决定者、接受 PR 与生效日期尚未建立，不代表已批准。

## 方案摘记

先生成验证过的私有不可变对象，后短事务激活 Share；项目级额度预留和幂等保证发布一致。每次媒体访问先查当前授权。

## 替代与代价

P0 不提供可绕过网关的公开 CDN 或长期存储下载地址，不缓存正向授权。

网关与数据库承担请求成本；撤销不能收回先前批准或下载的字节。

## 唯一详细依据

见[架构提案](../proposals/0001-architecture.md)第 8 节；G04、G08，以及[质量门禁](../testing/quality-gates.md)。本条仅为决策摘记；细节修改先改架构提案，不复制出另一套规则。
