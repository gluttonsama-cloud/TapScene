# TapScene 点演

在 Android 手机上，把录屏做成可点击、可分支的演示，用于成果展示、方案评审和短流程教学。

[业务功能](#业务模块) · [页面安排](#页面与流转) · [数据表](docs/architecture.md#数据层) · [API/SDK](docs/architecture.md#应用接口层) · [当前任务](docs/tasks.md)

`android/` 已有本机媒体、项目、步骤、热点和点击预览。新增主入口为“编排点击链并录屏”：选择目标 App、顺序定位短按点，隐藏定位层后确认起始页并授权全屏录制，录屏就绪后串行播放一次；真实 MP4、完整计划和执行日志保留本机，录后继续手动取帧校正。录制增量接入“开始录制 → 操作目标 App → 停止并整理画面候选 → 批量选择与逐帧校正”。候选只依据画面变化，不代表记录到点击；离线 OCR 增量提供所选候选批量识别、标题建议与人工文字框遮挡；文字区域建议已接入当前安全画面，生产托管仍待实现；安全区域裁片与固定版本 AI 数据包已接入源码，实际验证状态见当前任务。观看包增量支持固定修订、实际内容复核、封存、导出及独立导入播放，平台验证状态见当前任务。已有录屏导入和手动校正继续可用。候选确认后可显式按顺序生成“下一步”通路；它是作者编排的画布外按钮，手动画面热点与分支继续保留。录制系统行为待设备验证。

## 开发入口

- 验证基线：Android 8.0 / API 26 起；compile / target API 36；JDK 17、Gradle 8.13、AGP 8.13.2、Kotlin 2.2.21、Media3 1.9.4。正式兼容设备范围待实测。
- 已装上述工具和已接受许可的 Android SDK 时，运行 `gradle -p android :app:assembleDebug :app:lintDebug`；APK 在 `android/app/build/outputs/apk/debug/`。当前未附 Gradle Wrapper 二进制。
- `ci/gate` 核对合成 AVC/HEVC 素材与项目 SQLite 约束、离线包安全反例及共用播放器状态机、构建 APK、运行 Android lint 与权限检查；有可用硬件加速时才运行模拟器媒体冒烟，否则明确记录 `NOT_RUN`。构建通过不代表设备检查通过；成功产物保留 7 天。
- 独立[云端 Android 运行入口](tools/runtime-checks/README.md) 在固定 API35 软件模拟器中检查合成目标的真实点击、录屏和静态等待时长，专用 harness 不执行旧全量媒体 suite。实际结果以独立 `ci/android-runtime-smoke` 的精确提交和产物为准；不代表实体手机验收，产品版本仍为 31。
- CI 以 `-PcompatibilityPreview=true` 构建现有 `com.tapscene.preview.hevc` 包名（名称“TapScene 开发版”）；不再增加包名。CI 原始 APK 使用临时调试签名，交付前须按 [本地重签说明](tools/signing/README.md) 使用同一专用开发证书并核对实际输出。首次换签不能覆盖旧版；不要为签名冲突卸载有数据的旧版或清除数据。长期私钥备份尚未完成，开发环境重建后仍有丢失风险。
- 当前路径：录制或导入 → 整理候选 → 批量选择 → 同页调帧/按需遮挡/确认实际输出并下一张 → 步骤标题、说明与热点 → 本机点击预览。候选最多 30 个，实际采样最多 361 次，可能遗漏短暂变化；帧时间为毫秒精度。选择候选不等于隐私复核，只有真实生成并确认的派生 PNG 进入步骤。无敏感信息可不加遮挡。
- 录制每会话请求系统授权，使用有停止入口的前台服务；不录声音。手动模式不采集点击；点击链只保存作者编排及执行回调，服务在编排/播放期间读取窗口包名、类名和全屏状态，不读取节点内容、键盘文本或通知。可见敏感输入仍可能被录入，后续必须复核。锁屏/系统停止结束会话；进程中断不自动重新录制，封口成功但登记未完成的本机片段可显式重试或删除。
- 点击链需 Android 13 / API 33 以上核对窗口显示器，旧系统保留手动录屏与取帧；固定默认显示器、完整屏幕和编排时方向；尺寸、方向或捕获区域变化结束本轮，旧坐标不会自动缩放。定位覆盖层由用户亲自开启的无障碍服务提供，不额外申请悬浮窗权限；未知/非目标窗口暂停，恢复需重新确认当前页。停止或中断不自动续播，结果未知的点击不自动重试。点位按系统公开的状态栏、导航栏和屏幕缺口实际边界检查，不把 App 自己的返回键和底部栏统一禁掉；最多 40 点、计划总长最多 120 秒，仅一次短按播放；按压时长须低于设备长按阈值至少 50ms，检测到放大或触摸探索时停止派发。系统设置/授权和可识别的认证页面阻断，同 App 内支付和验证界面无法全面识别，仅编排普通演示操作。
- 点位列表默认紧凑显示，点击一项展开等待与改序，坐标和按压时长在高级参数中。目标 App 浮层可切换“浏览页面”，暂藏点位和大面板，保留可拖动的“继续定位”按钮；手动切页后恢复定位，计划保留。浏览不会开始播放，录制前包括小按钮在内的浮层全部移除。
- 点击链专用共帧管线保留真实 MP4，动作边界从编码前同一 FBO 固定私有 PNG，按真实编码样本与封口容器序号核对；手动录屏仍用 MediaRecorder。诊断 uptime/elapsed 不是 PTS，静态无新帧/PNG失败为 Missing，不阻断健康录像与既定播放、不补图或重试点击。独立证据入口已接入，候选/热点消费 UI 另行实现；原图仍须遮挡和实际输出复核，不能直接交付。细节见 [共帧证据](docs/frame-anchors.md)。
- 手动录制在 Android 12L / API 32+ 使用系统固定 Surface 等比居中适配旋转/窗口变化，输出可有留边；API 34 内容尺寸回调记录粗略几何，不作为真实点击或视频 PTS。API 26–31 检测显示变化后结束本段，需重新授权；这些系统行为尚待真机验证。
- 本机交付：检查 → 固定修订 → 逐项确认实际图片、完整过渡视频、标题/讲解/动作和项目文字/包清单 → 实际试走全部动作及一次完整路径 → 封存。固定底部显示复核进度，当前类完成后“下一项”直达未完成项，仅导航，不自动确认内容。旧候选和版本不随草稿修改；未封存副本及已封存版本均可从演示库管理。
- 观看包只包含白名单 JSON、已复核 PNG 与可选无声 H.264 SDR 过渡；导入到隔离区，经结构、图、路径、字节/摘要、图片及整段视频实际解码检查后原子加入演示库，不覆盖项目。包完整性不代表作者或隐私认证；导入外部包不继承本机作者复核结论。schema 1 静态包保持兼容；有视频边时使用 schema 2，旧版 App 不支持该格式。含可见区域时使用 schema 3 / scene-regions-3，旧静态/视频包继续兼容。包不含原片、原 OCR、私有路径或脚本；AI 包另以 `.tapscene-ai` 导出。
- 系统分享：先生成独立只读快照，再打开系统选择器；不经过文件保存，也不自动上传。临时入口 24 小时后拒绝新读取，已接收副本和已打开的读取不受影响。缓存最多 8 份、200 MiB，满额时可保存到文件；失败或返回后需主动重新分享。
- 单张截图：项目首页或项目“素材 → 导入截图”，仅选择一张 PNG/JPEG；取消选择不建项目。先核对完整静态图片、方向与容量，再在同一画布按需遮挡、生成并复核真实 PNG，确认后才创建项目或加入步骤。透明区域统一铺黑，原图不进入交付；无敏感内容可不遮挡。最多 20 张当前引用的原截图，删除最后一个引用它的步骤或改用安全底图后释放原图和配额。截图关系由作者编排，加入步骤后可主动识别当前安全图文字区域；不提供批量导入。
- 已有步骤可从“画面 → 替换画面”或“遮挡 → 重新遮挡”重新取帧、校正本步遮挡并复核实际 PNG 后原子替换；保留步骤 ID、文字和动作。未保存文字不会自动提交，返回/取消保留原步骤；提交边界取消按重读结果提示。换图使本步裁片及入/出过渡失效，需重新处理，旧封存版本不变。原片缺失时可在当前已保存安全 PNG 上继续追加不透明遮挡，逐次复核实际输出后替换；旧遮挡已烧入，不能恢复原像素。仅能撤销本轮未提交的新矩形，重新进入始终使用最新正式安全图。
- 区域：单步编辑器的“区域”在实际安全图上框选或输入像素，设置名称、组、叠放次序和局部锚点；生成真实 PNG 后查看并复核。每步最多 12 个、全项目最多 80 个。换底图或改范围使裁片及其复核失效，旧成品不变；候选封存前再次查看实际裁片。
- AI：演示库选固定版本 → AI 配置，按真实边选有限路径（可明确回访）、停留和白名单效果，选择两种画布；长路径列表滚动，底部固定步数/时长和继续选路/检查保存；复核独立计划/文件清单后系统保存。包保留完整 scene 与安全资产。独立 [Remotion 消费者](remotion-adapter/README.md) 读取并渲染，手机不执行 Remotion；完整静态 `.tapscene-ai` 可隔离核对后建为独立新草稿；视频包、裸 JSON 和编辑器无法无损表示的内容明确拒绝。带入完整图和有限动画计划，全部须在本机重新复核。
- AI 回流：项目首页选 AI 包 → 核对完整待导入内容（可明确选一个本机封存版本比较）→ 建为新草稿。步骤来自完整 scene，访问计划中的回访不复制步骤；共享图片展开为独立私有副本后再次检查 50 MiB 和本机空间。没有所选本机版本时明确无法核对原版；包 ID、摘要和 recorded/authored 声明不认证作者，没有对应原导出计划快照时不显示路径差异。外部图片、文字、区域、动作和试走均重新复核，原项目与版本保持原样。
- 项目“动画计划”保留逐项访问、停留、效果参数和稳定编辑标识；更改画面/区域/图后保留失效引用并提示修复，改停留不会删效果。坏配置可暂存但阻断生成；通过后随固定候选保存精确计划，新封存版本绑定自己的摘要。封存页只读这份计划，要修改需回草稿重新封存。
- 步骤更多菜单可复制已保存的单步，副本紧跟原步，保留文字、终点和出口目标；自环仍回到副本自身。复制当前安全画面，不依赖原片，也不自动接入路线；本步未保存输入须先处理。区域需重新生成复核，过渡需重设；原步和旧版本保持原样。
- 项目更多菜单可复制完整已保存项目：新项目独立保留步骤、连线、自环、起点、区域、已保存过渡、原录屏/截图及动画计划。所有步骤修改和面板输入须先处理；缺失原素材明确提示，安全正式画面缺失则不复制。副本重新复核，不带旧封存或分享状态；中断重试按同一操作结果恢复。
- 热点页可主动“识别文字区域”：仅本机读取当前正式安全 PNG，最多显示 8 个短单行文字框建议；点选后可改名称和范围，必须选择目标步骤或明确结束，再保存本步。文字框不代表按钮或真实点击，不自动连线；识别失败或超限仍可手画。画面更新使旧建议表单失效，输入继续暂存，但须取消后重新选区；外部包当前安全 PNG 可本机识别，仍须在交付前人工复核。
- 只有点击“按此顺序生成通路”才创建或重建下一步动作；普通分镜排序不改变连线。每步可在“分支”里改标签、目标或移除下一步。删除目标后保留待补目标提示，不自动跳过该步或当作结束；预览返回沿实际访问历史。
- 顶层仅“项目 / 演示库”；项目内为“步骤 / 素材 / 检查与交付”；进入统一编辑器后收起这两层导航，只保留画面/热点/分支/遮挡/区域模式。未实现执行禁用，布局不填假项目、版本或进度。
- 界面检查使用官方 Compose / Layoutlib 主机渲染，布局样例只存在于 screenshotTest。渲染图不等同真机截图，不证明媒体解码、触控或系统选片行为。
- 项目预览读取持久化派生 PNG 与已复核短片，支持起点、结束、热点选择、实际访问历史返回和重来。边可裁剪并生成无声过渡，完整播放后显式确认绑定；单段实际 ≤10 秒，按边绑定累计 ≤60 秒，提交前失败或取消保留原绑定，提交后取消显示重读结果。播放完成或明确跳过才进入既定目标，故障可重试或静态前进；退出使旧回调失效。成品另行完整复核后封存为 `.tapscene` 包，交付页可对当前选中的本机封存版本打开系统分享，由作者选择接收应用。
- 原片、取帧位置和遮挡保存在 `noBackupFilesDir`；备份及设备迁移规则显式排除应用数据，OEM 迁移行为仍待设备验证。没有接入 ML Kit：其官方指标外传行为尚不满足本项目隐私条件。
- 用户已反馈兼容修复后基础导入可用；这不是完整设备、性能或隐私验收。项目编辑增量仍须另行设备验证，构建/静态/合成素材结果与真机结果分别记录。

本地托管开发已加入 `server/`、`runtime-ts/` 与 `web-player/`，使用本机 PostgreSQL、私有文件存储和合成邮箱完成逐资产发布及网页观看。启动见 [本地托管说明](server/README.md)；Android 仅在独立 `hostedDebug` 开发变体接入本机托管；默认 `debug` / `release` 仍无网络权限。生产服务尚未接入。

本机开发目标：`gradle -p android :app:assembleHostedDebug :app:lintHostedDebug`（不签名，不作为手机交付包）。使用固定 `http://127.0.0.1:4173`，没有任意服务器输入。未来设备调试可用 `adb reverse tcp:4173 tcp:4173` 连接电脑上的本地服务，不能改成 `10.0.2.2` 或放宽服务端 Host/IP 门禁；当前真机链路未验证。

托管开发流程：明确选择演示库里已在本机复核封存的版本 → `@example.test` 合成账号登录 → 手动输入本机服务收件箱中对应 challenge 的验证码 → 核对固定版本、实际文件范围/体积、账号、地址与 1/7/30 天期限 → 点击确认。只发送 canonical scene 与声明的安全 PNG、区域裁片和过渡 MP4；任务使用独立私有快照，原项目或本机版本删除不影响已开始任务。中断后按原账号、原请求及幂等键恢复，整资产重传；服务端校验中不显示发布成功。停止观察与取消服务端任务分开，提交后取消如实显示已发布，并提供另行撤销。账号、任务、版本管理均以服务器回执为准；登出不撤销已发布链接。

登录会话凭据与任务日志分离，Android Keystore 密文保存在排除备份的目录。取消登录清除验证码并隔离迟到回调，已收到的迟到会话尝试撤销；若创建会话响应完全丢失，客户端无法取得或撤销未知令牌，服务端开发会话最长一天到期。设备网络、Keystore、反向端口与后台生命周期仍待实机核验。增量主机检查见 [托管客户端检查](tools/hosting-checks/README.md)。

## 业务模块

| 模块 | 功能 | 用户操作 | 结果 |
|---|---|---|---|
| 项目 | 本机制作、复制、恢复 | 新建项目；选录屏或截图；复制已有项目 | 独立项目和活动草稿；无需登录；显式创建可先建立空项目，取消选片不额外建立项目。 |
| 素材 | 裁剪、取帧、追加、替换 | 选文件和区间；指定新素材接入位置 | 本机私有副本；保留源文件；替换前列出受影响步骤、连线、区域和复核。 |
| 本地整理 | 分段、OCR、热点与重复状态建议 | 批量选择画面，按需采用文字建议并校正动作；必要时手动取帧 | 确认项进入正式图；失败片段可重试；重新分析保留人工编辑。端侧 OCR 属于首版功能。 |
| 步骤 | 代表帧、标题、讲解、排序、拆分与合并 | 编辑步骤；并排比较重复候选；确认合并 | 每个状态保留稳定 ID 和来源；表单、弹窗、键盘、滚动位置分别判断；拖动只改变列表顺序。 |
| 热点与分支 | 矩形热点、枚举选择、有限流程 | 画热点；选已有目标或结束；为多结果写标签 | 播放已有素材支持的流程；作者新编排的跳转需确认；待补录结果先留草稿。 |
| 录制过渡 | 静态切换或短视频 | 为一条边选片段、裁剪、加固定遮挡 | 单段 ≤10 秒、累计 ≤60 秒；移除全部原音轨；移动敏感信息需覆盖完整运动范围。 |
| 隐私 | 不透明遮挡、文字修订、实际输出复核 | 遮挡画面；改讲解和标签；看重新生成的图片及完整视频 | 真实脱敏资产；自动检测只提供线索；改动使相关输出、封面、裁片和复核失效。 |

### 素材、容量与使用范围

| 项目 | 首版设计限额或使用方式 |
|---|---|

| 录屏 | 每项目最多 3 段；总时长 ≤5 分钟；单段 ≤3 分钟、≤200 MiB；全部原素材 ≤500 MiB。 |
| 格式 | H.264 / H.265 由本机 Surface 解码；支持固定横竖屏、旋转元数据、非整数/VFR，10 位不等于 HDR。普通缺色彩字段按 Media3 的 SDR 默认解释；明确 PQ/HLG 需 API 29+及实际 tone-map 能力，字段不完整的 HDR 另报转换限制，不静默当 SDR。输入最长边 ≤8192、≤40 MP，GPU 等比缩至短边 ≤1080、长边 ≤2400 后取帧；输出按编码器能力协商画布，烧入遮挡并重编码无声 H.264 SDR。导入检查首/中/末实际帧，不承诺整片已解码；动态格式变更在处理时检测。 |

| 包大小 | 每个交付包及解压后资产总量均 ≤50 MiB。 |
| 托管 | 同项目最多 5 个有效版本；有效期 1/7/30 天，默认 7 天；达到上限后由作者选择撤销旧版。 |
| AI 动画 | 1080×1920 或 1920×1080；30 fps；有限访问序列；普通 MP4 仅播放视频。 |
| 手机操作 | 全部创作、检查、导出在 Android 手机完成；触摸入口至少 48 dp；密集热点可用文字动作列表。 |
| 模拟范围 | 只演示已录制或作者明确补充的内容；点击仅切换演示状态；输入只显示预置示例，与原 App 业务接口隔离。 |
| 隐私与权限 | 原片、原 OCR、源路径、未脱敏像素、编辑历史留在本机私有域；敏感草稿与缓存排除系统云备份和设备迁移，迁移排除需实测；只访问用户选定文件，尊重受保护录屏。 |
| 本地分析 | 端侧分段与 OCR 离线运行；SDK 关闭非必要指标外传；原素材、敏感数据不进入日志或外部模型。 |

## 页面与流转

目标主流程：01 项目 → 02 录制操作 → 03 自动候选与人工确认 → 04 步骤 → 05 单步编辑 → 07 预览 → 08 检查 → 09 复核 → 10 交付。旧视频导入和手动校正作为 02 的补充模式。下表为完整产品安排，不代表全部执行能力已实现。

### 共用规则

| 场景 | 规则 |
|---|---|
| 保存与恢复 | 编辑器文字、热点、分支和未应用面板输入自动暂存到本机；实际落盘后显示“已暂存”，失败保留输入并可重试。重新打开项目先恢复全部步骤草稿；同字段冲突保留双方供选择。名称、热点和下一步面板点击“保存本步”即可验证并事务保存本步，失败保留原输入；顶部保存仍可提交画布/终点改动。成功暂存后返回直接保留，未落盘先完成暂存屏障，失败或冲突可重试、继续编辑或明确放弃本步；其他步骤草稿不会自动提交或删除。 |
| 单次撤销 | 单步编辑器及打开的面板可撤销最近一次未保存编辑；同一文字字段连续输入合为一次，切换焦点或字段结束合并，拖动/删除动作各计一次。撤销后继续自动暂存，保存失败仍可撤回；只保留本次编辑会话，不提供重做。保存成功、放弃修改、打开/取消面板、离开本步或正式修订变化清空历史；重新打开保留已暂存输入，不恢复撤销历史。图片、遮挡、区域和过渡不在此撤销范围。 |
| 预览与原片 | 预览使用安全派生媒体；原片回看放在明确标注的本机私有入口。 |
| 复核 | 检查实际图片、完整视频、文字、封面/裁片和包清单；内容改变使关联复核失效。 |
| 任务 | 显示真实阶段与完成量；有分母才显示百分比。取消只清本次临时产物，已保存内容保留。 |
| 文件与发布结果 | 完整写出才算导出成功；系统分享返回不证明已发送；服务端确认后才显示发布或撤销成功。 |
| 播放 | 上一步沿实际访问历史；重来清空历史；过渡锁重复操作，关闭或切步使旧回调失效。 |
| 访问 | 网页恢复页面/断点、读取媒体均重验到期与撤销；错误页说明原因，临时故障可重试。已下载副本无法收回。 |
| 回流 | 外部包重新校验与复核；回流生成新草稿，来源版本保持原样。 |
| 无障碍 | 文字动作可代替热点；网页支持键盘焦点，Android 支持屏幕阅读器；内容按纯文本展示。 |

```text
       后续改动产生新修订              发现问题 → 修改 → 重生成
```

## 从点击链整理独立演示

录制页和点击链工作台均可打开“整理已录制点击链”。选择动作范围，依次复核实际画面、拖改并确认点击区域及后继，生成独立的新项目。原录屏项目及其未保存编辑保持原样。

- 中间画面可选前一动作后的画面或下一动作前的画面；作者明确选择它代表该步骤，并在这张图上确认下一动作的位置。完成回调只表示系统手势完成，不代表按钮命中或业务成功。
- 缺图、中断或未知动作会保留待补项，不能跨过它们生成连线。可缩小到完整连续段，或切换“仅加入画面”，再在项目内手动修正。
- 遮挡后须查看真正生成的 PNG 并确认；捕获有效不会自动成为隐私复核。相同真实帧共用一个步骤，回访及同页多个点击明确保留；不同帧不因看起来相似而合并。
- 一次最多 40 步、80 个动作、每步 6 个热点；超量先缩小范围，不会省略后半段。生成按实际步骤和已确认动作计数。
- 新项目独立复制原片和正式安全图片，删除原录屏项目后仍可使用新项目素材手工修正。生成前原片或锚点失效时拒绝保存；取消、重开和提交结果不明通过原操作回执恢复，避免创建重复项目。
