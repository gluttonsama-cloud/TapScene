# 点演 产品规格说明

手机录屏生成可点击可分支交互式演示

版本 v0.1    2026年10月9日    方案定义阶段

点演把手机 App 的屏幕录制整理成可点击、可选择分支的交互式演示。创作者在 Android 手机上完成录入、步骤整理、热点与分支编辑、隐私检查及交付；观看者按提示体验有素材依据的有限流程，不需要拥有原 App 的账号。

首版面向成果展示、方案评审、短流程教学，并新增把结构化演示交给AI或Remotion继续制作动画的交付场景。核心交付是有清晰起点、真实录制依据和可检查终点的演示，而非从录屏恢复一套可以真实办事的 App。

本规格确定 v0.1 的产品行为、页面、数据边界与验收方式。P0 表示首版必须闭环的能力，P1 表示增强项；文中的时长、容量和性能目标均需在指定测试设备及样本上验证，不代表产品已经实现或已取得测试成绩。

## 1 产品定位与首版决策

产品的价值集中在手机内完成制作、保守且可追溯的分支整理、交付前真实脱敏，以及同一份有限状态演示的在线与离线播放。录屏转交互演示已有商业产品，本方案不将这一类别或移动观看本身宣称为首创；差异需要通过与现有流程对照验证。相关竞品依据见 R1–R3。

| 决策面 | 确定的首版方案 |
| --- | --- |
| 创建与维护 | P0 仅 Android 原生创作；项目默认保存在本机，不要求先注册或上传。iOS 通过网页观看。 |
| 观看形式 | 采用一个引导式分支播放器。录制画面配合真实热点、步骤说明和路径选择；不设置测试打分模式。 |
| 智能辅助 | 本地规则和 OCR 辅助分段、提取文字、提出热点候选；涉及分支语义、同页合并或不确定位置，由人确认。 |
| 观看交付 | 离线数据包由点演 Android 播放器导入；可选发布已脱敏资产到 HTTPS 链接，浏览器无需安装点演。 |
| 动画与AI交付 | 另选AI工程包，导出安全媒体、结构化JSON和可见区域素材；Remotion在电脑或选定云端适配渲染。 |
| 隐私底线 | 原始录屏留在本机。遮挡须写入输出像素，并检查文字、缩略图、音频和包内文件。P0 无云 AI，未来增强需单独说明上传内容。 |
| 版本原则 | 发布版本不可变；修改生成新版和新链接。旧链接不静默改内容，已下载离线包不能被远程收回。 |

### 明确边界

- 点演只模拟已录制或由作者明确补充的体验。点击不会操作原 App，不触发真实下单、支付、登录、发消息、改设置或任何业务接口。

- 滑动、文本输入、加载、键盘展开等动态过程以录制过渡或明确标注的示例动作表达。虚拟输入不校验真实账号，不采集观看者密码或其他真实凭据。

- 没有素材依据的页面、异常结果和权限状态不能由系统补成“已验证”分支。可以留为待补录节点，但存在待补录目标时不得发布该路径。

- 不提供一键克隆 App、自动恢复业务逻辑、跨 App 自动操作、测试题库、观看打分、企业知识库、团队实时协作或通用视频剪辑工作台。

## 2 用户角色与使用场景

| 角色 | 是谁 | 负责的事情 |
| --- | --- | --- |
| 动画制作者 | 创建者本人，或由其选择的AI工具及桌面动画制作者。 | 读取AI工程包，调整有限路径及动画编排；不取得原素材或在手机中执行外部脚本。 |
| 创建者 | 学生项目组和小型移动产品团队的产品、设计或开发成员；也包括制作一项短流程说明的人。 | 在手机上录入、整理、确认和交付；拥有本地草稿及本人账号下发布版本的管理权。 |
| 观看者 | 评委、老师、项目成员、合作方或功能试用者。 | 体验有限路径，查看说明、返回和重来；不能编辑、访问源素材或操作原 App。 |
| 发布创建者 | 创建者在选择托管链接时登录最小管理账号。 | 管理本人不可变版本与链接到期/撤销；不是团队管理员，不自动获得草稿云备份。 |

以下场景覆盖本版承诺的用途。三个观看类主场景共用同一个编辑器与播放器，不拆成多套模式；AI与动画交付复用安全资产和结构，增加独立导出配置。

### 场景一 成果展示与答辩辅助

触发与输入：已有能运行的手机项目，要让接收者快速理解主流程及一种成功、失败或替代结果。使用演示账号和样例数据，录下同一任务的两三条路径。

创建和交付：作者确认状态和热点，补一条分支，处理隐私并导出。现场可用预先安装的点演播放器断网体验，也可让观众扫描已发布链接在浏览器观看。

成功标准：观看者能从起点走到结果、比较另一分支并返回；无需原 App 账号，点击不产生真实提交。

场景边界：可作为讲解和离线备用。当赛事或课程要求原软件现场实际运行时，点演包不能替代该项实机验收。

### 场景二 产品方案评审与流程沟通

触发与输入：团队需要比较一个入口下的多种情况，例如报名成功、名额已满或主动取消。一段线性视频难以让接收者按问题选择路径。

创建和交付：作者把多段录屏接入同一演示，明确各出口的含义，确认看似相同的界面是否真的处于同一状态，发布固定版本供异步查看。

成功标准：各路径不串线；同页不同表单值、键盘、弹窗或选项不会被误合并。接收者知道自己正在看哪一版。

场景边界：点演承载流程本身，讨论和反馈可发生在现有沟通渠道；首版不增加需求管理、评论系统或协作白板。

### 场景三 功能上手与重复教学

触发与输入：新功能投入试用后，创建者经常要解释同一段操作，希望别人能自己按节奏学习。每份演示围绕一个任务，推荐5–20个关键状态。

创建和交付：作者录制标准操作，必要时增加常见错误路径；给关键动作写中文提示，复杂输入和滑动改为预置示例或短过渡，并设置明确完成页。

成功标准：观看者可暂停、看说明、返回和重来；知道屏幕中的输入及提交只是示例，不被要求填写真实信息。

场景边界：适合短流程熟悉，不替代原软件帮助中心、完整课程、考试测评或任意问题的智能客服。

### 新增场景 AI协作与动画交付

触发与输入：已有可点击演示，希望快速做介绍视频、点击讲解、局部聚焦或组件区域浮出展示，继续复用已整理的素材和路径。

创建和交付：作者在手机上选定一条路径，框选并命名需要强调的可见区域，另导出AI工程包；在电脑或明确选择的云环境，由AI及受信Remotion适配器制作动画。

成功标准：AI能按稳定字段读取媒体、文字和坐标，无需重新猜画面；成片忠实于所选路径。兼容JSON修改可作为新草稿回流并复核。

场景边界：区域拆解基于已可见像素，不还原隐藏背景、真实控件逻辑或React组件；动画渲染不在Android内执行，也不自动开通收费云服务。

### 自然覆盖的次场景

| 场景 | 怎样使用 | 边界 |
| --- | --- | --- |
| 功能更新说明 | 替换发生变化的少量状态，生成新版本。 | 不用新建一套视频剪辑或营销模板功能。 |
| 帮助朋友或家人 | 把自己会做的一项手机操作变成可重复看的说明。 | 只用示例数据；不远程操控对方手机，不代其办事。 |
| 问题过程说明 | 把已录到的问题和触发过程整理成可点击路径。 | 不推断根因，不替代日志、抓包或自动化测试。 |
| 软件课程练习 | 解释界面与操作顺序，演示作业的有限路径。 | 不做成绩、学习能力评估或真实考试。 |
| 无网展示与临时备份 | 提前把脱敏包导入点演，在无网时重放。 | 首次安装和文件传输须提前完成，不能临场承诺零安装。 |

首版不适合连续游戏、地图拖动、绘画、多点触控、3D 操作，或要求任意输入都得到真实结果的搜索、推荐和聊天系统。没有授权的素材，以及无法完成隐私处理的内容，不应进入公开或持链交付。

## 3 完整操作链与页面结构

### 创建者的一次完整任务

系统录屏 → 新建项目 → 选择并裁剪素材 → 本地生成候选 → 确认状态与热点 → 接入分支并修正文案 → 遮挡与逐项复核 → 遍历全部边及关键路径 → 生成固定快照 → 导出离线包或主动发布链接。

录制前提示只做一项任务，使用虚构示例数据、关闭无关通知并在关键画面短暂停留。P0 不在点演内接管其他 App，不要求源码或控件树，也不把内置录屏入口列为完成主流程的前提。

### 观看与维护

观看者打开有效链接，或将离线包导入点演，了解模拟说明后开始；按热点或文字选项选择路径，查看录制过渡，返回、重来或到达结束页。画面内的返回按钮是作者指定动作，播放器的“上一步”按真实访问历史回退，两者明确区分。

维护时在本机草稿中替换受影响素材，重新检查热点、连线与隐私，再生成新版本。账号能恢复已发布版本的管理，不恢复从未上传的本地源素材。自己的脱敏包可以复制为新草稿，但无法恢复被去除的内容。

| --- | --- | --- |

## 4 录入与项目管理

### F01 项目建立与本地恢复

操作与结果：创建者输入名称和一句演示目标，选择新建或复制已有项目；生成本地草稿，不要求账号。项目列表显示最近修改时间、节点数、待处理问题和发布版本数量。

规则与异常：每次明确编辑后保存草稿；长任务显示阶段、进度和取消入口。App 被中断后，已保存编辑仍可恢复；删除项目二次确认，并说明它不会自动撤销独立发布的链接。

验收要求：关闭并重开 App，草稿仍能编辑；取消生成不破坏已确认步骤；复制项目生成独立项目标识，原项目不变化。

### F02 导入录屏与素材检查

操作与结果：P0 通过系统文件选择器、相册选择或系统分享入口导入录屏。选择后检查容器、编码、可解码性、时长、画面方向和可用空间，并保留来源名称及时间轴。

规则与异常：不要求无障碍服务、通讯录、全盘照片访问或原 App 账号。对不支持、损坏、超限或黑屏素材明确说明原因；可重新录制、裁短后重导或使用截图补充，不伪造画面。

验收要求：有效素材可预览和定位时码；取消选择不新建空项目；拒绝权限仍能查看已有项目；受保护画面不被标为正常录入。

### F03 裁剪和补充录制

操作与结果：作者设置需要的起止时间，排除等待、通知或录错部分；可以追加另一条录屏作为失败路径或替代操作。补充截图只能形成静态状态，并标为作者编排，不能被描述为已有录制过渡。

规则与异常：裁剪只改变项目引用范围，不改写源文件。新素材先独立分析，再由作者指定接入位置；不能因页面标题相同就替换已有状态。

验收要求：裁掉的片段不出现在输出中；追加片段可回到对应源素材和原时码；取消接入不会丢失原路径。

### F04 本地分析和安全降级

操作与结果：本地完成基础抽帧、画面变化检测、OCR 与候选步骤整理；默认不上传素材。生成过程展示可理解的状态：检查素材、整理步骤、准备编辑。

规则与异常：分析失败仍允许手动取帧、创建状态、添加热点和连线。P0 不提供云 AI。必要的本地模型应随安装提供；若另需下载，首次使用明确说明准备条件，未就绪时仍可手工制作，不能暗中转云。

验收要求：在必要本地能力已就绪后，断网可走通基础流程且不外传素材；正式候选边均由作者确认，高把握也不能自动变为已确认；失败不会把空白结果覆盖已有草稿。

## 5 画面状态与步骤整理

### F05 状态分段和源素材依据

操作与结果：系统建议把录屏分成稳定的画面状态和短过渡。一个状态包含展示画面、标题、说明及来源；节点的含义是“此时屏幕的状态”，不是抽象页面名称。

规则与异常：同一页面上的表单值、键盘、弹窗、选项、登录状态和滚动位置变化，均可能形成独立状态。作者可调代表帧、前后切分点、顺序和节点名称；每条生成说明与过渡保留源素材和时码。

验收要求：任何步骤均可一键回看来源；同标题但不同表单值或弹窗的测试样例不会被无确认合并；手动拆分后热点与来源能重新校验。

### F06 同类状态建议与合并确认

操作与结果：系统只提示“可能重复的状态”，并展示两边画面、OCR 差异及来源。作者可以保留两者或确认合并，确认后仍可拆分或撤销。

规则与异常：合并前必须检查进入动作、画面状态和离开动作是否一致；录制中的时间相邻也不直接证明真实点击因果。视觉相似不能证明两条路径可以互相组合；来源不支持的连线保留为待处理，不自动生成新路径。

验收要求：未确认的建议不改变图结构；撤销恢复节点、边和来源；确认合并后若丢失有效分支，校验必须阻止发布。

### F07 步骤说明与缺失内容

操作与结果：基于可见文字和录制顺序生成简短中文草稿；作者可以修改标题、提示和选择项文案。生成文案必须能回到对应画面，未展示的信息以待补充提示呈现。

规则与异常：禁止凭空补写账号权限、真实支付结果、隐藏错误原因或录屏没有证明的功能。作者自行添加的讲解标记为作者补充，不伪装成系统从录屏中验证的事实。

验收要求：在故意缺失后续结果的素材中，系统不得自动产生“提交成功”；缺录目标可留在草稿，但不能包含在已发布可达路径中。

## 6 热点 分支与手机编辑

### F08 热点建立与精确调整

操作与结果：系统提出可能的点击区域；作者在画面上点选、拖动和缩放矩形热点，绑定“进入已有状态”或“结束演示”。热点可命名，必须有可读的操作标签。

规则与异常：录屏通常不包含真实触点，热点属于候选。低把握结果需确认；支持画面缩放和局部放大调整，热点位置采用相对内容画面的坐标，不能受播放器留白影响；触摸目标按至少48 dp设计，拥挤时提供文字动作列表。

验收要求：同一演示在不同宽高比手机及网页上，热点仍覆盖目标；边缘热点可选中；未确认热点、无目标热点和重叠冲突必须可定位修复。

### F09 分支建立和路径接入

操作与结果：作者从某状态添加两项或多项选择，分别指定有素材依据的目标状态，并写清“按什么选择”。可以在同一源状态放多个热点，也可显示底部选择列表。

规则与异常：每条边记录触发、目标、可选过渡及来源类别。录制提取边保存时码；作者指定跳转须显式确认并标为作者编排。允许列表→详情→列表等用户显式触发环，不允许自动等待循环；缺失页面不能自动补造。

验收要求：从每个分支都能到达终点或明确出口；删除目标、重复选项、不可达节点及自动循环被检测；同一热点有多个结果时显示选择面板，不猜业务条件；分支选择后只播放绑定过渡。

### F10 滑动 输入与短视频过渡

操作与结果：滚动、键盘展开和加载可使用静态前后状态加提示，必要时加入已录制短视频过渡。输入动作只展示预置示例内容，播放器不要求观看者输入真实账号或密码。

规则与异常：P0 优先静态画面；短视频按单段不超过10秒、项目累计不超过60秒的设计上限约束，原始音轨统一移除。每段必须逐段审阅；不能用首尾静帧通过代替整段通过。

验收要求：过渡结束后进入准确目标状态；点击无效区域不触发原 App；超限片段需缩短或转静态；输出音轨检查为无原始音频。

### F11 手机上手和编辑反馈

操作与结果：默认用按顺序的步骤卡片编辑，提供选中步骤预览、说明、热点、分支和隐私入口；分支用局部路径视图展示，避免把大画布缩到手机上。

规则与异常：重要编辑即时显示效果，支持撤销最近操作；拖动时显示选中对象和对齐反馈。系统返回键先退出当前编辑层，再回项目；未完成长任务与待保存状态必须明确。

验收要求：不用电脑可完成从导入到分支预览和导出；同一对象编辑后与预览一致；误删、误合并和误连线至少有撤销或明确恢复路径。

### F12 结构校验和路径预览

操作与结果：发布前列出阻断问题和提醒项，并可点入对应状态。阻断项包括缺起点、缺终点、断边、缺媒体、非法循环、未确认候选、待补录目标和隐私复核失效。

规则与异常：作者可从当前状态或起点预览，覆盖全部边和指定关键路径；有回访环时不声称穷举无限路径。预览中显示调试标记；正式成品不带编辑控件、内部来源链接或未脱敏素材。

验收要求：一个含两条分支的示例必须逐条走完，且发布校验不只检查主路径；修复后问题状态自动刷新，未修复阻断项不能被静默忽略。

## 7 隐私处理与成品复核

### F13 敏感内容提示与人工遮挡

操作与结果：本地规则及 OCR 提示手机号、邮箱、账号、地址、通知内容等疑似敏感文字，作者可自行增加遮挡。提示不是安全证明，页面上始终保留手动检查入口。

规则与异常：静态画面使用不透明遮挡并写入输出像素。视频 P0 只提供覆盖整段的固定不透明多块遮挡；移动信息必须遮住完整运动区域，影响教学时改为静态状态。自动跟踪遮挡留到 P1。

验收要求：对预置假手机号、假地址、二维码和通知测试，输出像素中不可恢复被遮挡信息；关闭覆盖层、解包或缩放均不能看到原始内容。

### F14 复核范围和失效规则

操作与结果：每个状态及每段视频有“待复核／已复核”状态。作者检查全部帧呈现、说明、选项、OCR 派生文案、缩略图、封面、文件名和元数据；视频另检查音轨确已去除。

规则与异常：修改素材、裁剪范围、画面尺寸、遮挡位置或面积、步骤文案及相关派生资产后，对应复核立即失效。复核绑定内容摘要，不能只靠一个永久勾选框。

验收要求：修改已复核视频任一遮挡后，发布再次被拦截；缩略图、列表封面和导出资产均由脱敏结果生成；原始 OCR 和源录屏不进入交付包。

### F15 输出重检与发布确认

操作与结果：导出或上传前，生成独立的脱敏成品并重解码检查：检查文件清单、真实像素、残余文字线索、媒体完整性、音轨和元数据。作者查看发布前摘要后主动确认交付。

规则与异常：检测到残留线索或资产不一致时回到对应节点，不能自动把它标为安全。系统说明检查覆盖范围及局限；不承诺自动识别全部隐私，不使用“绝对安全”等表述。

验收要求：构造只在中间帧出现的敏感信息、文字副本和原素材混入包内的反例，检查需发现或由必需人工审阅拦住；失败不生成可访问的半成品链接。

## 8 观看体验

### F16 引导式分支播放

操作与结果：播放器先显示演示标题、用途、版本与“模拟操作”说明，再从起点进入。有效热点有轻量提示，分支选择项可直接点击；每步同时提供文字说明。

规则与异常：点击非热点区域不跳步，必要时给一次位置提示。顶部显示当前步骤和退出入口，底部提供上一步、重新开始及可用操作；不显示原 App 的可执行登录或支付入口。

验收要求：观看者无需原 App 或原账号可走通所有录制路径；点击热区只改变演示状态；无热点节点有明确的继续或结束动作，不会卡在画面上。

### F17 返回 断点与终点

操作与结果：上一步根据本次访问历史返回，保留已走路径，不按节点编号猜测；重新开始清空本次路径。完成页说明到达的结果并允许重看、返回分支或退出。

规则与异常：同一版本可在本机保存最后位置；重开时询问继续或重头看。链接到期、撤销或版本不一致时不能借断点状态跳过访问检查。浏览器清缓存后允许从头开始。

验收要求：A→B→D 与 A→C→D 两条路径进入 D 后，“上一步”分别回到 B 和 C；重新开始回 A；恢复断点前检查版本与资源有效性。

### F18 适配与可访问性

操作与结果：内容画面按原比例缩放并留白，热点坐标相对画面映射；横竖屏变化不重建错误状态。文字可读，不能只用颜色表达可点击和风险。

规则与异常：为热点提供文字替代入口与无障碍标签；网页支持键盘焦点与清晰选择态。视频有暂停及跳过到结果入口；播放期间锁定重复触发，结束只进入本次已选目标，不自动串播后续路径。

验收要求：在小屏、长屏、横屏和桌面浏览器上覆盖相同目标；文字放大仍可操作；仅使用文字选项也能完成主路径和分支。

## 9 离线与链接交付

### F19 离线演示包导出与导入

操作与结果：导出为点演定义的纯数据包，包含清单、图结构及已脱敏媒体。接收者首次需要安装点演 Android 播放器；导入后不联网即可观看，不需要安装原 App 或注册原账号。

规则与异常：包内只允许受限 JSON、PNG／JPEG 和受支持视频，不携带任意 JavaScript、HTML 脚本、外部网址媒体引用或原录屏。导出不是完整工程备份。作者可把自己的脱敏包复制为新草稿，继续改文字和连线；无原片时不能重新选帧或恢复遮挡前内容。

验收要求：把包传到一台没有原 App 的 Android 手机，开启飞行模式后导入并遍历分支；每个资产均随包完整提供；不存在“手机双击 ZIP／HTML 必然离线运行”的宣传。

### F20 包验证与失败隔离

操作与结果：导入前检查格式版本、文件清单、哈希或内容一致性、引用媒体、支持类型和解压后总大小；拒绝目录穿越、重复路径覆盖、嵌套归档、异常解压体积、恶意脚本和不完整资产；哈希只用于完整性，不代表作者身份认证。

规则与异常：在隔离临时目录完成验证后才加入演示库。拒绝旧版不兼容或损坏包时，显示原因及重新导出建议；不会覆盖同名现有项目或其他演示。

验收要求：缺文件、被篡改媒体、非法路径、解压炸弹和带脚本包全部被隔离拒绝；正确包成功导入；失败前后原项目内容不变。

### F21 选择性云发布与账号

操作与结果：本地制作完成后，作者主动选择“发布链接”。托管发布要求可恢复的创建者账号，P0 暂定邮箱验证码登录；本地制作、离线包和观看者持链访问不要求账号。

规则与异常：先完成全部边及关键路径和隐私检查，再上传已脱敏清单和媒体。登录失效或上传中断保留草稿，可重试；异机登录只恢复已发布版本管理与撤销，不恢复本地原片和草稿。管理权限由服务器验证，不使用丢失后无法恢复的匿名管理令牌。

验收要求：未登录不阻断本地制作；登录后可查看本人已发布版本并撤销；其他账号不能管理；上传失败不产生半成品链接，重复重试不重复发布版本。

### F22 HTTPS 观看与到期撤销

操作与结果：链接对应一个不可变版本，持链接者在浏览器中观看，无需安装点演；iOS 通过此路径使用。有效期提供1天、7天和30天，默认7天；同项目活动版本最多5个，均为待验证设计政策。

规则与异常：页面与每次媒体请求必须统一检查权限和有效期；到期或主动撤销后，新请求拒绝访问。已下载、截屏或缓存内容无法远程收回，发布前明确说明，不把难猜链接说成强身份认证。

验收要求：到期后页面、缩略图与复制出的媒体地址均拒绝新请求；撤销无需删除本地草稿；已打开播放器下一次新请求被拦截；服务故障展示可重试提示。

## 10 维护 版本与恢复

### F23 新版发布与旧版保留

操作与结果：作者修改草稿后重新检查并创建新发布版本及新链接。旧版本内容与链接保持不变；发布新版时提示是否撤销旧版，默认不擅自撤销，也不延长旧版有效期。

规则与异常：版本列表显示版本号、创建时间、到期时间、状态和复制链接／撤销操作；多个有效版本独立管理。离线包包含版本号与内容摘要，已发出的包不被后来修改覆盖。

验收要求：发布 v2 后，v1 链接仍对应原内容和原到期时间；撤销 v1 不影响 v2；修改草稿不能改变任一已发布产物。

### F24 局部替换与关联失效

操作与结果：当原 App 改版时，作者替换相关素材或状态，系统展示受影响的热点、连线、说明、视频、缩略图及复核状态，让作者逐项修正。

规则与异常：变化不会直接写入已发布版本；引用已删除素材的步骤标为缺失。对无法可靠匹配的新旧画面，保留旧引用并要求人确认，不把热点静默迁移到错误按钮。

验收要求：替换按钮位置已变化的画面后，相关热点需重新检查；移除被多条边引用的节点时能看到影响范围并撤销；新版仅在完整校验后生成。

### F25 任务失败与空间清理

操作与结果：分析、脱敏、导出、上传分别保存任务状态；取消或失败仅清理本次临时产物。低存储、应用被杀、断网和账号过期均有明确恢复入口。本地自动保存只防进程中断，不防卸载或设备丢失，敏感素材与草稿排除系统云备份。

规则与异常：清理本地缓存前显示占用和影响；删除项目不等于撤销链接，撤销链接不等于删除源素材。删除不可恢复内容需明确确认，不能用“清理”掩盖数据丢失。

验收要求：在导出中途终止 App 后，已有项目和已发布版本保持可用；重复恢复不会重复资产或生成两个链接；空间不足时不留下看似完整的损坏包。

## 11 AI工程交付与动画扩展

点演输出不仅供观看者点击，也作为作者继续制作视频的结构化起点。观看包服务于点演播放器；AI工程包服务于作者选择的AI与动画工具；受信Remotion适配模板是独立开发产物，不混入来自外部的数据包。三者用途与执行边界分别说明。

### F26 AI工程包导出

操作与结果：作者在交付页另选“导出AI工程包”，选择演示版本与一条有限路径，得到安全媒体、版本化JSON与schema、状态/分支/热点/说明、来源类型、坐标单位和README。该交付与供观看者使用的演示包分别标明用途。

规则与异常：只附脱敏派生图和无原音视频，不因AI用途加入原录屏、原OCR、真实源路径或编辑历史。包含分支图与selectedPath；导出线性动画时必须选择具体路径，回访需明确有限次数。

验收要求：另一位使用者或AI读取README与schema后可定位每个状态、动作和资源；无原App依赖、无脚本夹带、无未使用私密资产；未选择有效有限路径不能生成动画时间轴。

### F27 可见区域拆解素材

操作与结果：作者在已脱敏画面上框选并命名可见区域，指定分组、层级次序和动画锚点；导出该区域的裁切图及bbox，供浮出强调、局部放大或并排拆解。

规则与异常：这只是从现有像素裁出的区域，不是恢复原App真实组件或React代码。被遮挡背景、控件后方内容和不可见图层不补造；原画面仍包含该区域，需以弱化底图或并排布局避免把重复画面误说成真实分层。

验收要求：裁切图与最终脱敏底图一致；框跨出画面被拦截；改底图或遮挡后区域裁切与复核失效；AI包不给出被遮挡前的像素。

### F28 Remotion适配与线性动画

操作与结果：首版产品须交付版本固定且可运行的独立受信Remotion适配模板，将选定路径转换为线性时间轴，支持点击指示、聚焦缩放、页面切换、标注和节奏调整；区域素材可用于浮出或并排动画。

规则与异常：在电脑或用户选择的云环境运行，不在Android中执行Remotion。模板固定Composition ID、版本和效果白名单；Remotion不会自动理解任意JSON。默认30fps，提供1080×1920竖屏和1920×1080横屏预设，原画面等比布局。默认桌面本地渲染，云服务与收费不自动启用。

验收要求：用同一AI包在两个画布预设生成一致的路径，热点与区域锚点转换准确；分支不被拼成未声明的顺序。本轮仅确定模板接口与验收合同，尚未开发；首版验收必须实际完成渲染。

### F29 兼容JSON回写为新草稿

操作与结果：AI可修改符合约定的文字、路径、时长建议或区域数据后，交回兼容JSON及必要安全资源。点演将其作为一个新草稿导入，列出与来源版本的差异，供作者审阅。

规则与异常：重新校验schema、版本、ID、资产、路径、安全类型、容量和隐私；外部“已复核”标记不直接生效。不能覆盖现有草稿或已发布版本，不能自动发布，也不执行任意JS或Remotion代码。

验收要求：合法改字与改路径可进入独立新草稿；非法资源、断边、超限、未知脚本和缺媒体均被隔离拒绝。外部动画工程本身不保证能反向导回点演。

### AI工程包最小合同

| 数据 | 字段与内容 | 解释规则 |
| --- | --- | --- |
| manifest | schemaVersion、exportKind、releaseId、title、资产清单及校验值。 | 区分观看包和AI包；不附可执行入口。 |
| states与transitions | 状态ID、图片ID、文字、出口、来源类型与已确认编排属性。 | 图结构可多分支，线性动画必须另给选中路径。 |
| hotspots | 相对状态画布的0–1归一化矩形与目标ID。 | coordinateSpace明确为归一化状态画布。 |
| regions | source-pixels的bbox、sourceWidth/Height、分组、zIndex及layer-normalized锚点。 | coordinateSpace明确为源图像素；与热点单位不混用。 |
| selectedPath与timeline | renderPlan含visits，每项visitId、stateId、selectedEdgeId、holdFrames；时间轴含startFrame、durationFrames。 | 源时码用毫秒，输出用整数帧；重复访问使用不同visitId，循环有限。 |
| assets与README | 脱敏图、裁切图、审阅视频、格式/单位/适配说明。 | 路径只指包内资源；说明与标签属于数据，不是执行指令。 |

时间、画布和来源必须显式记录。热点使用相对状态画布的0–1坐标；组件区域bbox使用源图像素并声明coordinateSpace、sourceWidth和sourceHeight，适配器统一换算，禁止无标注混用。此处源图指安全派生画面，不是原录屏或未脱敏帧。所有动画只改变展示布局，不能把作者编排误标成录制事实。

### 受信适配模板的实现合同

模板注册固定Composition，例如DianyanDemo；inputProps读取已校验JSON。JSON Schema定义交换格式，模板可另外用Zod校验，但两者不是同一接口。模板锁定依赖与adapterVersion，只实现页面停留、已录短视频、点击波纹/光标、聚焦缩放、页面转场、框选高亮及文字标注等白名单效果。未知效果、脚本表达式与动态组件导入均拒绝。

每次访问用独立visitId。源素材区间使用毫秒，输出区间使用固定fps下的整数帧，统一采用起点包含、终点不包含；适配时按同一舍入规则转换一次。renderPlan保存解析后的绝对起始帧和总长，calculateMetadata据此给出元数据。重叠转场须扣除重叠帧，普通标注不改变时长。普通MP4只包含所选线性路径，不再可点击分支。

审核后的媒体复制到受信模板的本地资源目录，再由staticFile加载；禁止由包内URL下载后备原片。模板README说明入口、Composition ID、props文件、素材位置、版本和输出路径。缺字体、缺媒体、未知schema、越界坐标和非法时长需明确诊断；字体及图标记录授权，中文缺字有替代策略。

矩形裁片可以带背景，须标明screenshotCrop；锚点按裁片局部0–1坐标记录。有作者提供的干净底板才做真正从页面移出再复原；没有时用放大引出、并排或抽象背景，不生成被挡住的内容。alpha只引用已存在且已确认的透明资产，不把矩形截图说成干净透明图层。

将AI包交给外部模型或云渲染属于创建者主动选择的下一步；点演导出不等于自动上传到任何AI服务。当前是规格与适配方案，模板代码、实际渲染效果和兼容JSON往返均需在开发阶段完成并验证。Remotion接口依据见R11–R16；上线前另核对适用许可。

## 12 输入输出与数据结构

### 首版设计限额

下表是控制首版范围的设计上限与验收目标，均未经过真机实测。导入、编辑、导出、服务端和播放器采用一致规则；不能将这些数值写成已证明的容量或性能。MiB 为二进制容量，MP 为像素数量。

| 对象 | 设计范围 | 边界行为 |
| --- | --- | --- |
| 内容规模 | 推荐5–20个状态；上限40个状态、80条边，每状态最多6个热点。 | 检验分支可理解性、触控操作和遍历校验。 |
| 录屏数量与时长 | 每项目最多3段；总时长5分钟；单段最长3分钟。 | 超限在分析前提示裁剪或减少素材。 |
| 录屏文件 | 单段≤200 MiB，全部原素材≤500 MiB。 | 导入前检查存储及复制成本，不静默截断。 |
| 录屏格式 | MP4／H.264／SDR，固定竖屏，最高1080×2400；帧率≤60。 | 分析和输出可规范化；其他格式不保证。 |
| 补充截图 | PNG／JPEG；最多20张；单图≤12 MP 且≤10 MiB。 | 截图属于作者编排，不自动推导未录制动作。 |
| 短视频过渡 | 单段≤10秒，项目累计≤60秒；统一去除原音轨。 | 逐段审阅和每帧固定遮挡烘焙。 |
| 交付资产 | 单个发布包及解压后资产总量均≤50 MiB。 | 打包前显示体积，超限可压缩、减少过渡或转静态。 |
| 托管链接 | 每项目最多5个有效版本；1／7／30天，默认7天。 | 第6个发布需先由用户撤销旧版或等到期。 |

固定竖屏以素材方向为准：混合横竖屏、HDR、未知编码与超基线分辨率应拦截并说明原因，不能承诺所有手机录屏均可导入。观看设备的旋转只做等比适配，不改变源素材。兼容机型、最低系统版本与浏览器版本在实现前通过小样验证后冻结。

### 核心对象关系

一个项目包含一个可变草稿和多份源素材；源素材通过实际时间戳锚定多个状态。状态通过热点及边连成有向图；边可以共享目标、分叉或显式回访。确认后编译为不可变版本，版本引用安全资产；托管发布记录只指向某个固定版本。显示编号和页面名称均不是对象身份。

| 对象 | 最小字段或关系 | 存储与约束 |
| --- | --- | --- |
| 项目 Project | 稳定项目标识、标题、目标、时间、来源素材清单。 | 本机；账号不自动备份此对象。 |
| 草稿 Draft | 可变状态、热点、边、文案、编辑历史和检查状态。 | 本机自动保存；生成任务锁定一份快照。 |
| 源素材 Source | 私有副本、格式、尺寸、时长、时间轴和原始摘要。 | 本机；原片、原 OCR 和源路径不进入交付。 |
| 画面状态 State | 稳定ID、代表帧、标题/说明、来源类型和素材时码。 | 显示排序不改变ID；结束状态明确标记。 |
| 热点与边 | 相对矩形、文字标签、目标ID、触发、可选过渡、来源类别。 | 录制提取或作者编排；不能附脚本/业务条件。 |
| 安全资产 Asset | 重编码图像/无音视频、相对路径、类型、大小和内容哈希。 | 只引用本版本文件，不引用原片或外部URL。 |
| 复核记录 Review | 检查范围、资产/文案摘要、确认时间和失效原因。 | 内容改变后不可沿用旧通过状态。 |
| 版本 Release | 不可变版本ID、图快照、最小清单、资产摘要、生成时间。 | 交付后不改写；新内容产生新版本。 |
| 发布记录 Share | 所有者、版本ID、链接标识、状态、准确到期时间。 | 服务端管理；每次页面和媒体请求均检查。 |
| 任务 Job | 任务ID、固定快照、阶段、错误和幂等请求标识。 | 用于恢复和重试；不能公开未完成产物。 |

源锚点用实际媒体时间戳或范围记录，不只依赖假定固定帧率的帧号。录制提取边保留来源时码；作者编排边保留确认记录。编辑端可追溯来源，观看端只得到必要说明及安全资产，不附原录屏、原 OCR、真实源文件名或本机路径。

### 输入与输出合同

| 阶段 | 允许输入 | 产生输出 |
| --- | --- | --- |
| 本地创作 | 作者明确选择的录屏及补充截图。 | 私有源副本、候选状态、可编辑草稿和待复核项。 |
| 安全编译 | 已确认的图、文案及隐私处理配置。 | 重编码静态图、无原音视频、安全缩略图、固定清单与摘要。 |
| 离线交付 | 通过检查的不可变版本。 | 纯数据演示包；播放器在点演本体中，包内没有运行脚本。 |
| 可选托管 | 作者主动确认的安全资产与交互图。 | 属于当前版本的HTTPS链接、准确到期时间及管理记录。 |
| AI工程交付 | 安全图与区域、有限路径及结构化语义。 | 独立AI包；经适配器制作线性动画，兼容JSON可新草稿回流。 |

本机原素材、原 OCR、未脱敏帧、模型上下文、缓存、撤销历史和敏感草稿均不得进入业务分析、崩溃报告或系统云备份。设备迁移的排除需按平台实际验证，不能仅凭一项配置承诺覆盖所有厂商。未复核项目用中性封面；最近任务、通知和错误日志避免呈现敏感画面或文字。平台依据见 R4–R8。

### 自动化与用户确认边界

| 类别 | 内容 | 执行原则 |
| --- | --- | --- |
| 可自动执行 | 格式和配额检查、候选抽帧/OCR、重复状态建议、图结构校验、安全资产生成、大小与清单检查。 | 结果可解释，失败不破坏原草稿。 |
| 必须由作者确认 | 热点目标与不确定位置、同类状态合并、作者编排边、敏感区域完整性、逐段视频、最终文案、每次交付。 | 确认绑定当前内容；相关编辑后失效。 |
| 必须由作者主动发起 | 创建者登录、向托管服务上传、选择有效期、撤销具体版本、删除本地项目。 | 登录不自动上传；发新版不自动撤旧版。 |
| 系统不能替用户猜 | 未录制页面、隐藏业务结果、同一热点的成功/失败条件、真实触点、脱敏是否绝对完整。 | 缺失时提示、要求补录或使用手动路径。 |

## 13 首版范围与增强项

### P0 必须完成

- 另行选择的AI工程包、版本化schema、可见区域裁切与动画锚点、版本固定且可运行的独立Remotion适配模板和有限路径时间轴、兼容JSON回写为新草稿。

- Android 本地项目、固定竖屏录屏导入、首尾裁剪、补充截图、本地自动保存和手工兜底。

- 规则/OCR 辅助的状态与热点建议、来源时码、作者编排标签、手机卡片编辑、同态合并确认及可撤销分支。

- 静态优先和限额短视频、全链真脱敏、逐段人工复核、相关修改使复核失效、输出重检。

- 唯一引导式播放器、真实历史回退、重来、文字替代操作、纯数据离线包及安全导入。

- 可恢复创建者账号、已脱敏资产可选托管、HTTPS 无安装观看、不可变版本、到期撤销与失败恢复。

### P1 另立需求后加入

- 自动全组件分割、复杂分层与抠图、Figma/SVG源图层对接；外部动画工程反向转换另行评估，不默认承诺。

- 云 AI 润色与复杂建议；按实际服务商、用途和选定已脱敏内容明确说明，保留纯本地制作路径。

- 自动遮挡跟踪、创建者新配音及其独立复核，更多素材编码、横屏和 iOS 原生编辑。

- 桌面 HTML 导出、跨设备工程备份或草稿同步、完整版本比较、稳定“最新版”链接别名。

- 密码或指定观看者访问、轻量评论/协作；观看统计如确有需求，另行明确采集目的和用户选择。

P1 的云 AI 不得静默接管失败任务。每次明确展示实际供应商、用途和要发送的已脱敏帧/文字，作者选择后才调用，并说明保留政策；拒绝不影响本地基础编辑。安装后的本地模型可用状态必须可见，未准备好时保留手动制作。

### 明确排除

真实业务前后端、任意 App 克隆、控制第三方 App、原账号登录态提取、真实输入/支付/表单提交、外部动作跳转、任意脚本与表达式、测试打分、复杂手势、营销线索收集和企业权限体系均不进入 P0。它们不应以“顺便支持”扩大首版验收范围。

## 14 验收与测试计划

验收分为确定性功能、安全检查、可用性及性能。下面是待执行清单，不代表已通过。含回访环的演示不可能穷举无限路径，因此覆盖全部边、明确的关键路径与已列异常，并报告覆盖范围。

### 统一端到端样例

使用自建、无真实个人信息的校园活动报名样例，录制报名成功、名额已满、取消报名三条路径。故意放入同页不同输入值/弹窗、没有触点的点击、短暂通知、滚动信息、一次视频过渡和一个手动编排跳转，形成可重复的标准输入。

| 用例 | 需要得到的结果 |
| --- | --- |
| A01 完整手机创建 | 首次使用者仅用 Android 手机，把标准样例整理成主路径和两个分支，修改一个热点，补一段作者编排说明，完成复核、导出和发布。 |
| A02 三路径和返回 | 逐条走报名成功、名额已满、取消报名；同一汇合状态的上一步返回各自真实来路；显式回访循环可退出，无自动循环。 |
| A03 状态合并防错 | 三张标题相同但输入值、弹窗或选项不同的画面不自动合并；手动确认后可撤销，边及来源恢复。 |
| A04 真脱敏与无原音 | 埋入假电话、假地址、二维码、中间帧通知和测试音轨；检查最终像素、全部视频帧、包内文本/缩略图/元数据和资产清单，无原片及原音轨。 |
| A05 复核失效 | 改遮挡、换帧、改视频范围、改说明或恢复旧版本后，对应项重新待检；未检查不能生成交付物。 |
| A06 真离线 | 另一台预装点演且没有原 App 的 Android 手机，在飞行模式下首次导入完整数据包，走完所有分支、过渡、返回和重来。 |
| A07 无安装网页观看 | 从新浏览器环境打开 HTTPS 链接，不登录观看账号、不安装点演，走完流程；Android、iOS 与桌面按兼容矩阵验收。 |
| A08 发布隔离与恢复 | 上传中断或回执丢失可恢复且不重复发布；失败不影响旧版；v2新链接、v1原内容和原到期时间均保持。 |
| A09 到期与撤销 | 到期和撤销后，新页面及直接媒体请求均拒绝；离线撤销不假报成功；新发布不复活旧链接。 |
| A10 包安全 | 篡改、缺媒体、路径穿越、异常解压体积、不兼容版本、非法脚本均被拒绝且不覆盖任何现有项目。 |
| A11 中断与配额 | 导入、分析、烘焙、导出、上传逐阶段中断；已保存草稿不丢。所有设计限额边界和超限一单位均有明确行为。 |
| A12 无真实操作及无默认外传 | 网络与权限检查证实播放器无原 App 业务调用；未选择云交付时原片、OCR、草稿和缓存不外传，不进入系统云备份。 |
| A13 AI结构化交付 | 独立AI/动画制作者按README和schema解析全部ID、路径、文字与素材；包内无原片、原OCR和执行脚本，资源只指包内文件。 |
| A14 画布与坐标 | 同一路径在30fps两种预设画布中等比显示；归一化热点和源像素区域经适配后落点正确，裁切块不暴露被遮挡像素。 |
| A15 动画语义与边界 | 点击、聚焦、标注、页面切换和可见区域浮出可渲染；分支按selectedPath线性化，回访次数有限；不生成隐藏图层或冒称真实React组件。 |
| A16 AI回写隔离 | 兼容JSON改字/改连接可导入独立新草稿并重新复核；坏schema、脚本、缺媒体、越界坐标和断边被拒绝，不覆盖或自动发布。 |

### 异常行为覆盖

| 触发情况 | 预期处理 |
| --- | --- |
| 取消选择或拒绝权限 | 回到原页面，不反复请求；已有草稿不变。 |
| 文件损坏 不支持 超限 | 指出具体文件和原因，允许移除、裁短或替代；不拖累其他有效素材。 |
| 原文件删除或云相册未下载 | 已复制验证的素材可继续使用；未完成导入明确要求重选或下载。 |
| 黑屏 保护内容 混合方向 | 提示不在支持范围或需替代素材，不绕过录屏保护，不伪造成功。 |
| OCR或分段失败 | 保留原素材和手工取帧/热点入口；重试不覆盖人工修改。 |
| 存储不足 后台被杀 过热 | 停在可恢复阶段，保留已保存草稿；不删原片，不产出损坏成品。 |
| 网络差 验证码失效 登录取消 | 仅阻断托管能力；本地编辑和离线包继续可用。 |
| 上传超时 回执丢失 | 按同一请求查状态并幂等重试，未完整版本不公开，不重复生成链接。 |
| 离线撤销或撤销失败 | 显示待联网撤销和仍可能可访问；服务端确认前不显示成功。 |
| 视频加载或解码失败 | 显示原因和重试/跳过，进入既有目标静态状态；不取回原片兜底。 |
| 导出目标不可写 分享取消 | 保留项目；完整写出才算导出成功，调起分享页不算已送达。 |

### 评估方法

| 维度 | 记录方法 |
| --- | --- |
| 生成质量 | 使用标注答案对比分段、漏掉关键状态、热点候选位置及错误合并；误合并单独计数，不被平均准确率稀释。 |
| 编辑成本 | 与手动选帧加热点流程比较：完成同一成品总耗时、人工修正次数、无效点按和需要重新录制次数。 |
| 观看可用性 | 让非作者在不口头解释的情况下走主路径与分支，记录完成率、卡住位置、误认为真实提交的情况。 |
| 安全与稳健性 | 记录每类埋入隐私是否在任何一帧或派生产物残留；测试中断、坏包和访问撤销，不以抽样首页代替全路径。 |
| 性能 | 在记录型号、Android版本、内存、温度、素材规格的设备上测处理耗时、峰值内存、包大小和发热；对照上限素材与推荐素材。 |

测试数据可由独立的样例 App 和固定脚本生成，答案来自该样例的真实事件与状态，而不是让被测识别算法给自己出答案。还应加入获得授权的真实录屏，避免只在自制界面上有效。真机验证必须涵盖解码、内存、发热、后台限制和网页兼容。

首轮报告至少交代素材数量与类型、设备及浏览器版本、原始结果、人工修正成本和失败案例。自动分析效果不与用户修正后的成品成功率混算；平均值不能掩盖错误合并、单帧隐私残留或撤销旁路。性能阈值在小样基线后冻结，不先编造已达标成绩。

## 15 竞赛展示与开发顺序

### 一次可检查的现场演示

- 先展示带虚构敏感信息的原素材和明确目标，再现场导入点演并生成候选，说明识别结果是建议。

- 现场修正一个热点，拒绝一个同页异态合并，接入一个分支；打开来源时码，让评委看到录制依据与作者编排的区别。

- 对静态图和短视频设置固定遮挡，完成复核；再移动一次遮挡，展示复核失效与重新生成的行为。

- 生成离线包，在另一台预装点演的 Android 手机断网导入，走主路径和分支；用网页入口展示无安装观看。

- 发布新版展示新旧链接独立，再撤销指定旧版，验证页面及直接媒体新请求失效，同时说明已下载副本不能收回。

- 展示同一安全项目的AI包，选择一条路径生成点击/聚焦动画和可见区域浮出；将兼容JSON改动导入新草稿，证明交付可以继续加工。

- 最后展示一次坏包、断链或中断恢复，不只展示精修过的成功样例。

参加软件创新赛事时，需要现场真实运行点演自身的导入、编辑、检查、生成和播放。不能仅播放点演的预录演示来宣称 App 已完成。用于说明其他软件成果的点演演示，也不能替代赛事或课程明确要求的原软件实机运行。

### 按风险安排实现顺序

- 先验证支持格式的手机解码、本地安全资产生成、纯数据包导入和单路径播放器，确认完整离线链。

- 再完成手机步骤编辑、来源锚点、显式分支与校验、复核依赖和中断恢复，使手工兜底先独立成立。

- 随后加入分段、OCR、热点与相似状态建议，用人工修正成本证明辅助价值。

- 并行定义版本化AI包及适配合同，完成可见区域、有限路径动画和安全JSON回写，复用同一脱敏资产。

- 最后完成可恢复账号、不可变发布、统一资产访问检查、到期撤销及真实设备兼容；云 AI、协作等不挤占上述验证。
