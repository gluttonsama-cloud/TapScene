# ADR 004 重编码脱敏与实际输出复核

状态：Proposed。日期：2026-10-09。决定者、接受 PR 与生效日期尚未建立，不代表已批准。

## 方案摘记

静图和每帧视频均重新生成安全像素，移除原音和不允许元数据；Review 绑定实际输出摘要、配置与处理版本。

## 替代与代价

预览覆盖层、edit-list trim 或自动 transmux 不能作为脱敏。

安全输出耗时和磁盘成本较高；必须验证移动编码器、失效传播和全部派生资产。
