# TapScene 点演

在 Android 手机上，把录屏做成可点击、可分支的演示，用于成果展示、方案评审和短流程教学。

[业务功能](#业务模块) · [页面安排](#页面与流转) · [数据表](docs/architecture.md#数据层) · [API/SDK](docs/architecture.md#应用接口层) · [当前任务](docs/tasks.md)

`android/` 已有本机媒体、项目、步骤、热点和点击预览。录制增量接入“开始录制 → 操作目标 App → 停止并整理画面候选 → 批量选择与逐帧校正”。候选只依据画面变化，不代表记录到点击；OCR、自动热点、观看包、托管与 AI 交付仍待实现。已有录屏导入和手动校正继续可用。候选确认后可显式按顺序生成“下一步”通路；它是作者编排的画布外按钮，手动画面热点与分支继续保留。录制系统行为待设备验证。

## 开发入口

- 验证基线：Android 8.0 / API 26 起；compile / target API 36；JDK 17、Gradle 8.13、AGP 8.13.2、Kotlin 2.2.21、Media3 1.9.4。正式兼容设备范围待实测。
- 已装上述工具和已接受许可的 Android SDK 时，运行 `gradle -p android :app:assembleDebug :app:lintDebug`；APK 在 `android/app/build/outputs/apk/debug/`。当前未附 Gradle Wrapper 二进制。
- `ci/gate` 核对合成 AVC/HEVC 素材与项目 SQLite 约束、构建 APK、运行 Android lint 与权限检查；有可用硬件加速时才运行模拟器媒体冒烟，否则明确记录 `NOT_RUN`。构建通过不代表设备检查通过；成功产物保留 7 天。
- CI 以 `-PcompatibilityPreview=true` 构建现有 `com.tapscene.preview.hevc` 包名（名称“TapScene 开发版”）；不再增加包名。CI 原始 APK 使用临时调试签名，交付前须按 [本地重签说明](tools/signing/README.md) 使用同一专用开发证书并核对实际输出。首次换签不能覆盖旧版；不要为签名冲突卸载有数据的旧版或清除数据。长期私钥备份尚未完成，开发环境重建后仍有丢失风险。
- 当前路径：录制或导入 → 整理候选 → 批量选择 → 同页调帧/按需遮挡/确认实际输出并下一张 → 步骤标题、说明与热点 → 本机点击预览。候选最多 30 个，实际采样最多 361 次，可能遗漏短暂变化；帧时间为毫秒精度。选择候选不等于隐私复核，只有真实生成并确认的派生 PNG 进入步骤。无敏感信息可不加遮挡。
- 录制每会话请求系统授权，使用有停止入口的前台服务；不录声音，不采集点击、键盘文本或无障碍事件。可见敏感输入仍可能被录入，后续必须复核。锁屏/系统停止结束会话；进程中断不自动重新录制，封口成功但登记未完成的本机片段可显式重试或删除。
- Android 12L / API 32+ 使用系统固定 Surface 等比居中适配旋转/窗口变化，输出可有留边；API 34 内容尺寸回调记录粗略几何，不作为真实点击或视频 PTS。API 26–31 检测显示变化后结束本段，需重新授权；这些系统行为尚待真机验证。
- 只有点击“按此顺序生成通路”才创建或重建下一步动作；普通分镜排序不改变连线。每步可在“分支”里改标签、目标或移除下一步。删除目标后保留待补目标提示，不自动跳过该步或当作结束；预览返回沿实际访问历史。
- 顶层仅“项目 / 演示库”；项目内为“步骤 / 素材 / 检查与交付”；进入统一编辑器后收起这两层导航，只保留画面/热点/分支/遮挡/区域模式。未实现执行禁用，布局不填假项目、版本或进度。
- 界面检查使用官方 Compose / Layoutlib 主机渲染，布局样例只存在于 screenshotTest。渲染图不等同真机截图，不证明媒体解码、触控或系统选片行为。
- 项目预览只读取持久化派生 PNG，支持起点、结束、热点选择、实际访问历史返回和重来；不会直接播放原片。现有无声短视频复核/文件保存保留，尚未接入步骤过渡；项目没有分享或观看包导出入口。
- 原片、取帧位置和遮挡保存在 `noBackupFilesDir`；备份及设备迁移规则显式排除应用数据，OEM 迁移行为仍待设备验证。没有接入 ML Kit：其官方指标外传行为尚不满足本项目隐私条件。
- 用户已反馈兼容修复后基础导入可用；这不是完整设备、性能或隐私验收。项目编辑增量仍须另行设备验证，构建/静态/合成素材结果与真机结果分别记录。

## 业务模块

| 模块 | 功能 | 用户操作 | 结果 |
|---|---|---|---|
| 项目 | 本机制作、复制、恢复 | 新建项目；选录屏或截图；复制已有项目 | 独立项目和活动草稿；无需登录；显式创建可先建立空项目，取消选片不额外建立项目。 |
| 素材 | 裁剪、取帧、追加、替换 | 选文件和区间；指定新素材接入位置 | 本机私有副本；保留源文件；替换前列出受影响步骤、连线、区域和复核。 |
| 本地整理 | 分段、OCR、热点与重复状态建议 | 逐项确认画面、文字和动作；必要时手动取帧 | 确认项进入正式图；失败片段可重试；重新分析保留人工编辑。端侧 OCR 属于首版功能。 |
| 步骤 | 代表帧、标题、讲解、排序、拆分与合并 | 编辑步骤；并排比较重复候选；确认合并 | 每个状态保留稳定 ID 和来源；表单、弹窗、键盘、滚动位置分别判断；拖动只改变列表顺序。 |
| 热点与分支 | 矩形热点、枚举选择、有限流程 | 画热点；选已有目标或结束；为多结果写标签 | 播放已有素材支持的流程；作者新编排的跳转需确认；待补录结果先留草稿。 |
| 录制过渡 | 静态切换或短视频 | 为一条边选片段、裁剪、加固定遮挡 | 单段 ≤10 秒、累计 ≤60 秒；移除全部原音轨；移动敏感信息需覆盖完整运动范围。 |
| 隐私 | 不透明遮挡、文字修订、实际输出复核 | 遮挡画面；改讲解和标签；看重新生成的图片及完整视频 | 真实脱敏资产；自动检测只提供线索；改动使相关输出、封面、裁片和复核失效。 |
| 动画区域 | 可见截图裁片 | 在当前安全图上框选；填名称、分组、叠放次序、锚点 | 裁片和坐标仅含安全图可见像素；保留截图外观；移动组件需要真实干净底板。 |
| 预览检查 | 逐边试走、关键路径、问题定位 | 从起点或当前步预览；检查并修正问题 | 上一步沿实际访问历史；允许显式回访；覆盖记录绑定图摘要。 |
| 安全版本 | 生成、逐项复核、封存 | 固定草稿修订；审阅实际像素、文字、整段视频及包文件 | 不可变版本；未确认候选、断边、缺媒体、无效复核均阻断交付。 |
| 离线交付 | Android 观看包 | 导出纯数据包；系统保存或分享；接收者安装播放器后导入 | 完整导入后断网可看；无需原 App 账号；包仅含观看数据；已发出的包无法远程收回。 |
| 可选托管 | 固定版本链接、到期、逐版撤销 | 邮箱登录；选有效期；上传安全版本；管理链接 | 持链可看的 HTTPS 页面；仅上传已复核安全资产；旧链接内容固定；撤销以服务端确认结果为准。 |
| AI 交付 | 独立数据包与实际动画模板 | 选有限路径、画布、停留时间和区域；导出 AI 包 | 数据包保留完整已纳入图；独立受信 Remotion 模板在电脑或明确选择的云环境实际渲染 MP4。 |
| AI 回流 | 兼容 JSON 和安全包导入 | 选包；核对文字、连线、路径、时长、区域差异；确认导入 | 独立新项目和草稿；保留来源关联；重新验证、重新复核；原草稿和旧发布保持原样。 |
| 维护 | 任务恢复、本机存储、发布管理 | 继续中断任务；清缓存；分别删除项目或撤销链接 | 保留已完成资产和旧交付；账号可恢复发布管理，本机源片和草稿需留在原设备。 |

### 素材、容量与使用范围

| 项目 | 首版设计限额或使用方式 |
|---|---|
| 步骤与动作 | 推荐 5–20 个状态，上限 40 个；最多 80 条边；每状态最多 6 个热点。 |
| 录屏 | 每项目最多 3 段；总时长 ≤5 分钟；单段 ≤3 分钟、≤200 MiB；全部原素材 ≤500 MiB。 |
| 格式 | H.264 / H.265 由本机 Surface 解码；支持固定横竖屏、旋转元数据、非整数/VFR，10 位不等于 HDR。普通缺色彩字段按 Media3 的 SDR 默认解释；明确 PQ/HLG 需 API 29+及实际 tone-map 能力，字段不完整的 HDR 另报转换限制，不静默当 SDR。输入最长边 ≤8192、≤40 MP，GPU 等比缩至短边 ≤1080、长边 ≤2400 后取帧；输出按编码器能力协商画布，烧入遮挡并重编码无声 H.264 SDR。导入检查首/中/末实际帧，不承诺整片已解码；动态格式变更在处理时检测。 |
| 补充截图 | PNG/JPEG；最多 20 张；单图 ≤12 MP 且 ≤10 MiB；截图间关系由作者编排。 |
| 包大小 | 每个交付包及解压后资产总量均 ≤50 MiB。 |
| 托管 | 同项目最多 5 个有效版本；有效期 1/7/30 天，默认 7 天；达到上限后由作者选择撤销旧版。 |
| AI 动画 | 1080×1920 或 1920×1080；30 fps；有限访问序列；普通 MP4 仅播放视频。 |
| 手机操作 | 全部创作、检查、导出在 Android 手机完成；触摸入口至少 48 dp；密集热点可用文字动作列表。 |
| 模拟范围 | 只演示已录制或作者明确补充的内容；点击仅切换演示状态；输入只显示预置示例，与原 App 业务接口隔离。 |
| 隐私与权限 | 原片、原 OCR、源路径、未脱敏像素、编辑历史留在本机私有域；敏感草稿与缓存排除系统云备份和设备迁移，迁移排除需实测；只访问用户选定文件，尊重受保护录屏。 |
| 本地分析 | 端侧分段与 OCR 离线运行；SDK 关闭非必要指标外传；原素材、敏感数据不进入日志或外部模型。 |
| 外部包 | 仅解析允许的数据和本地安全资产；脚本、表达式、外部媒体 URL、损坏或缺文件的包隔离拒绝。 |

容量上限需真机实测；最低 Android、目标机型、浏览器和性能阈值在实现前确认；超限显示具体原因，保留完整输入供调整。

## 页面与流转

目标主流程：01 项目 → 02 录制操作 → 03 自动候选与人工确认 → 04 步骤 → 05 单步编辑 → 07 预览 → 08 检查 → 09 复核 → 10 交付。旧视频导入和手动校正作为 02 的补充模式。下表为完整产品安排，不代表全部执行能力已实现。

### 共用规则

| 场景 | 规则 |
|---|---|
| 保存 | 确认编辑后自动保存；失败保留屏幕中的修改，提供重试；重启恢复最近已保存内容。 |
| 预览与原片 | 预览使用安全派生媒体；原片回看放在明确标注的本机私有入口。 |
| 复核 | 检查实际图片、完整视频、文字、封面/裁片和包清单；内容改变使关联复核失效。 |
| 任务 | 显示真实阶段与完成量；有分母才显示百分比。取消只清本次临时产物，已保存内容保留。 |
| 文件与发布结果 | 完整写出才算导出成功；系统分享返回表示已交给分享工具；服务端确认后才显示发布或撤销成功。 |
| 播放 | 上一步沿实际访问历史；重来清空历史；过渡锁重复操作，关闭或切步使旧回调失效。 |
| 访问 | 网页恢复页面/断点、读取媒体均重验到期与撤销；错误页说明原因，临时故障可重试。已下载副本无法收回。 |
| 回流 | 外部包重新校验与复核；回流生成新草稿，来源版本保持原样。 |
| 无障碍 | 文字动作可代替热点；网页支持键盘焦点，Android 支持屏幕阅读器；内容按纯文本展示。 |

### 创作页

| 页面 | 上中下布局 | 按钮 | 去向 |
|---|---|---|---|
| 01 项目首页 | 上：标题、设置、搜索。中：项目行，含修改时间、步骤数、问题、任务。下：项目/演示库、新建。 | 新建、选择录屏、导入自己的包；项目更多：重命名、复制、管理发布、删除。 | 项目→04；任务→12；新建填名称/目标后→02；导入→15；发布→14；设置→18。 |
| 02 录制与素材 | 上：返回、项目名。中：录制范围/会话状态、来源片段；导入与手动校正为补充模式。下：开始/停止录制、整理候选。 | 开始时请求系统录制授权；正常操作目标 App；可选已有视频、手动定位和遮挡。 | 停止检查完成→03 批量选择与连续校正→04；可从已有素材重新整理候选。 |
| 03 候选确认 | 上：整理结果、来源片段。中：候选卡，含帧、时码、标题、热点、确认状态。下：加入已确认项。 | 调帧/分界、改标题、回看、保留/舍弃；逐条确认动作；比较/合并重复项。 | 确认后→04；热点待编辑→05；局部分析失败可重试或手动取帧。 |
| 04 步骤卡编辑 | 上：项目名、保存状态、撤销、更多。中：纵向步骤卡与局部分支。下：加步骤、预览、检查与交付。 | 点画面；改标题/说明；拖动排序；设起终点、插入路径、复制、拆分/合并、删除。 | 画面→05；追加素材→02；预览→07；检查→08；素材/版本/项目设置在更多菜单。 |
| 05 单步画面编辑 | 上：返回、步骤名、撤销、更多。中：当前画面、当前模式面板。下：画面/热点/分支/遮挡/区域。 | 选代表帧；画矩形；选动作/目标；添加选择；改遮挡；框区域；对象列表。 | 过渡→06；生成安全底图→12；返回先退模式，再→04；名称打开标题/说明表单。 |
| 06 录制过渡编辑 | 上：起始步→目标步。中：预览、时间轴、固定遮挡、单段/累计时长。下：保存过渡、静态切换。 | 选已有片段、裁剪、播放/暂停、逐帧、重放、遮挡、取消。 | 保存或取消→05；实际生成→12；整段复核→09。 |

| 页面 | 操作与失败处理 |
|---|---|
| 01 项目首页 | 未复核项目显示中性封面；取消选文件不额外建立项目。<br>删除确认说明本机损失，已有托管链接仍需单独管理。 |
| 02 录制与素材 | 录制仅当前会话与授权范围，停止即停止采集；不绕过受保护画面。<br>旧视频没有原始点击事件；候选不冒充精确触点。导入仍检查实际解码与空间，取消清理未完成副本。 |
| 03 候选确认 | 画面与动作分别确认；重复项并排比较后合并，可撤销。<br>重新分析只追加建议，保留人工编辑。 |
| 04 步骤卡编辑 | 排序保持连线；插入路径时明确选择要重连的边。<br>素材替换或删除先展示受影响步骤；待补录卡保留为草稿。 |
| 05 单步画面编辑 | 每次只显示一个模式；对象拥挤时用列表选取。<br>目标面板显示名称、缩略图和来源；多结果分别命名。<br>关面板丢弃未确认值；返回先退模式。 |
| 06 录制过渡编辑 | 固定遮挡覆盖整段运动范围；保存后待生成与整段复核。<br>超限或坏片可重选素材、裁短或改静态；取消保留原绑定。 |
