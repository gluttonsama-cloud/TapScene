## 开发规则

- 一次解决一个明确问题，使用任务分支和 Draft PR；标题为英文类型加中文，正文只写具体改动。
- main 经 PR，分支保持最新，最新 `ci/gate` 通过且讨论已解决；合并、部署和权限变更按相应授权执行。
- 按改动做必要增量检查，优先运行功能并看实际效果；安全、数据和恢复改动检查对应反例，结果按真实状态填写。
- 产品范围、隐私、费用或破坏性迁移有重要取舍时先说明并确认；界面交付真实操作、数据和进度。

## 已有步骤画面纠错增量

- 入口：单步画面“替换画面”与遮挡“重新遮挡”；同一画布调帧、遮挡、实际输出复核，确认后替换原步骤，不另建步骤或要求重连。
- 数据：替换上下文绑定项目、步骤、预期修订号和独立会话；从本步保存的遮挡开始，不写入素材工作台或其他步骤的遮挡。步骤身份、文字、动作与起终点保留；未保存的文字/动作不自动提交。
- 失效与恢复：本步区域裁片/复核及所有入出过渡失效；相关步骤的内存编辑草稿同步移除旧过渡引用。取消前未提交保留旧图；取消发生在原子提交边界则重读实际结果。旧封存版本资产保持独立。
- 缺源边界：原片缺失时继续查看已保存安全 PNG，不能重新取帧或恢复已遮挡像素；已补独立 image 来源契约：明确选择当前正式安全图追加遮挡，绑定项目/步骤/revision/资产摘要与尺寸；不伪造视频来源或 PTS。
- 核验：本地主机 SQLite 约束与 `git diff --check` 通过；新增 Android 数据/状态机测试与 Compose 主机截图随本 PR CI 核验。设备上的触控、真实解码与取消交互未验；无 KVM 的平台运行须记为 NOT_RUN，不能用编译或截图代替。

## 缺原片安全画面追加遮挡增量

- 生产入口：原片缺失或已是安全图片步骤时，选择“在安全画面上追加遮挡”；同画布添加本轮矩形、生成并查看实际 PNG、确认后替换。已烧入像素不可撤销，重新进入使用最新正式安全图。
- 数据：私有来源分为 videoFrame/image，SQLite v6 受控重建仅 states，完整核对所有原关系/文字草稿/恢复日志并保持失败回滚。image 不携带视频时间或假来源；历史资产身份不引用已清理文件。视频过渡仅列真实视频；图片步骤可另选视频。
- 保存：核对完整绑定与遮挡外逐像素不变，拒绝过期、跨步、混合来源和透明/改色输出。保留步骤身份、文字动作与未应用文字缓冲，使本步区域及所有入出过渡失效，旧封存版本不变；提交取消后重读实存结果。
- 已核验：主机 v1–v5→v6 全关系/复合 ID/五个迁移失败点回滚、非法来源组合与旧 SQLite 回归通过。生产 Compose 两张及 Android 构建、Lint、PNG/状态机增量随本 PR 最新 CI 核验；无设备时平台运行明确 NOT_RUN，不以主机或截图代替。

- 项目首页与素材页可选一张 PNG/JPEG；复用同画布遮挡、真实 PNG 复核和 writer，确认后才加入步骤，新项目与首步同一事务创建。取消选图或复核不建空项目。
- 实际格式、字节/像素/内存预算、完整 PNG/JPEG、EXIF 八方向和透明黑底规范化；原截图独立私有保存，输出重新编码，按当前引用限制 20 张并在删除/换底图后释放来源配额。
- 私有来源 v7 image 分支明确区分外部截图与已保存安全底图；旧数据逐字段保全、来源互斥、真实来源隔离及日志清理。成品依据为作者补充 authored，安全追加保持依据，不变更包 schema。
- 已核验：主机 SQLite v1–v6→v7 保全、失败回滚与非法来源组合；截图同核心合成安全反例。本轮 Android 编译、Lint 与三张生产 Compose 渲染以最新 PR CI 为准。无设备时系统选图、触控/取消、平台解码/SQLite 生命周期明确 NOT_RUN，不以主机解析或 Layoutlib 代替。
