# ADR 007 备份边界与撤销不复活

状态：Proposed。日期：2026-10-09。决定者、接受 PR 与生效日期尚未建立，不代表已批准。

## 方案摘记

本地敏感域排除云备份和设备迁移；托管恢复先停访问并核对撤销事实及水位，无法证明完整则保持旧链接禁用。

## 替代与代价

不以 allowBackup=false 或备份任务成功推断迁移隔离和灾难恢复已达成。

需要厂商迁移测试、独立恢复证据和明确保留政策；目标待服务商选择后冻结。

## 唯一详细依据

见[架构提案](../proposals/0001-architecture.md)第 5、10 节；G02、G04、G05、G08，以及[质量门禁](../testing/quality-gates.md)。本条仅为决策摘记；细节修改先改架构提案，不复制出另一套规则。
