## 接下来按这个顺序

1. 仓库保护与规范入主干：完成 main 保护和必需检查配置，合并当前文档 PR。
2. 验证高风险技术：目标 Android 机型的解码、逐帧脱敏与无原音输出、端侧 OCR 的离线能力和无非必要外传；确定最低系统及依赖版本。
3. 做第一个可用离线闭环：最小工程和数据包、本地项目、手动取帧/热点、真实脱敏复核、导出、另一台 Android 断网导入播放。
4. 完成手机分支编辑、真实历史返回、撤销、复核失效及中断恢复，再加入 OCR/分段/热点建议和限额短视频。
5. 完成 AI 包、可见区域、独立 Remotion 模板的两种画布实际渲染，以及 JSON 新草稿回流。
6. 完成账号、不可变托管、网页观看、逐请求到期/撤销和恢复验证，再做全部首版能力的真实设备验收。

每一步按一个可独立审阅的结果拆小 PR，相关 schema、必要测试和说明随实现补齐。
手工闭环是先实现的路径，不删减首版 OCR、AI/Remotion 或可选托管目标。
